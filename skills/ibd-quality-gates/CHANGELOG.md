## [0.7.0] - 2026-09-06

### 变更（data 组迁入：数值自洽核对器归属归位）

- **新增 `scripts/check_data.py`**：数值自洽核对器（data 组：金额文本格式 amounts / 数值前后一致 consistency / 合计勾稽 calc / 跨表比对 cross_table），md/txt/docx 双载体——md 草稿阶段跑数值一致门（改 md 零排版成本），docx 正式稿复核亦可跑；仅 Python 3 标准库零 pip 依赖
- **归属归位（解扣遗留张力）**：data 组原住 ibd-doc-review check_content.py（历史「格式核对」统称下打包），本质是内容层自洽关切（数字不一致要回头改内容）——整体迁入本 skill，逻辑单一事实源随之迁移；`ibd-doc-review` check_content.py 同步删除 data 组回归纯 text/table（样式/结构核对），`--checks data` 打印迁移提示
- **金额格式拆两层**：文本层（千分位/小数位，随 amounts 迁本 skill，与 G1 裸数字粗筛同族）+ 呈现层（表格内对齐/字号/合计加粗，留 review table 组）
- SKILL.md：执行流程 ①' 改本包 check_data.py、分工表/推荐顺序/依赖表/资源索引/description/格式边界同步；review 依赖段改「数值核对已内置不再外指」

## [0.1.0] - 2026-08-28

### 首版（从 ibd-doc-team 专家包沉淀，去重合并四份 MD 的共性质量框架）

- **数字五要素**：单位/时点/来源/精度/可比口径，含逐要素正反例表
- **反模式清单**：四类 21 条（数据类 7 / 论证类 7 / 表述类 6 / 编造类 2 红线），每条按「问题 → 为什么不行 → 怎么改」人话体撰写；已剔除团队协作类反模式（留在专家 MD）与格式/勾稽类（归 ibd-doc-review）
- **交付前自检 10 条**：从 writer MD 收敛，格式项标注与 ibd-doc-review 的衔接关系
- **质量自评量表**：6 维 30 分（1/3/5 三档），<25 分不交付
- **五道质量门 G1-G5**：G3「三方引用门」通用化为「引用可追溯门」；G4「方法论引用门」通用化为「来源对照门」，支持用户级配置注入私有索引
- **自动化脚本** `scripts/check_gates.py`：G2 绝对化扫描（带来源标注自动降级 WARN）+ AI 痕迹词扫描 + G1 裸数字粗筛；10 例自测
- **词表**：wordlist-absolute.txt（36 词）/ wordlist-ai-flavor.txt（25 词），与 ibd-doc-review 的 term_rules 体系共用约定
- 边界裁定：数值勾稽/金额格式/序号 → 归 ibd-doc-review；本 skill 管内容质量层
