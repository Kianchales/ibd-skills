# 反模式清单（四类 21 条）

每条格式：**问题是什么 → 为什么不行 → 怎么改**。扫描时逐条对照，命中即修，修完重扫到清零。
注意：本清单只收「内容质量」问题。团队协作类问题（如未查知识库就动笔）不在本 skill 范围内。

## 一、数据类（数据本身经不起追问）

### D-1 数字无来源、无时点
- **表现**：「净利润 5,000 万」——哪年的？谁的净利润？审计数还是预测数？
- **为什么不行**：无法验证的数字等于没有数字；监管问询第一个就问出处。
- **怎么改**：按数字五要素补全。`净利润 5,000 万元（2024 年度，来源：发行人审计报告）`。

### D-2 口径混着用
- **表现**：上半篇营收用「万元」，下半篇变「亿元」；这段用财年、那段用自然年；同一个「毛利率」前后算法不同。
- **为什么不行**：读者没法确认两处说的是不是同一个东西，直接怀疑数据可靠性。
- **怎么改**：全文统一口径；确需换口径时显式说明换算关系。禁用 FY/LTM、千元/万元混用不注明的写法。

### D-3 可比公司随手挑
- **表现**：「与同行业可比公司相比……」但没说可比公司是谁、为什么选它。
- **为什么不行**：挑过的样本支撑不起「行业水平」的结论，这是反馈问询的高频靶点。
- **怎么改**：列出可比公司名单 + 证券代码 + 选择标准 + 可比性说明。

### D-4 引用第三方份额没挂声明
- **表现**：「市占率 15%（来源：XX 咨询报告）」但没说明该数据未经独立审计。
- **为什么不行**：第三方行业数据通常未经审计，直接当事实用有披露风险。
- **怎么改**：紧跟声明「该数据未经独立第三方审计」+ 报告名 + 发布时间。

### D-5 技术参数想当然
- **表现**：制程节点、良率、产能利用率写得很具体，但没说这是量产数据还是研发中数据。
- **为什么不行**：不同验证状态的技术参数含义完全不同，臆造状态等于编造。
- **怎么改**：区分「量产 / 客户验证 / 研发中」三种状态 + 来源。

### D-6 法规引用过期或缺文号
- **表现**：引了已修订/废止的法规；或只写「根据相关法律法规」。
- **为什么不行**：法规时效性是法律审的核心关注点；「相关法律法规」等于没引。
- **怎么改**：核对最新有效版本，标全文号 + 条款 + 生效状态。

### D-7 数据获取过程的单位陷阱
- **表现**：从数据终端导出的数字，单位、币种、板块属性没核对就进了正文（实测教训：48 家北交所项目因未解析终端单位字段出错）。
- **为什么不行**：终端返回的原始字段可能带未解析的单位/币种标记，直接用会量级错误。
- **怎么改**：保留原始单位字段做溯源；对量级做常识校验（营收 11.2 元？显然错了）。

## 二、论证类（观点和数据脱节）

### A-1 证据链断裂
- **表现**：「公司盈利能力较强」——强在哪？哪个数支撑的？数据从哪来？
- **为什么不行**：投行文档的每个判断都要能沿「观点 → 事实 → 数据 → 来源」走一遍，断在任何一环都算无效论证。
- **怎么改**：每句结论性表述，自问「下一段读者会问凭什么」，答案就写在下一句。

### A-2 竞争地位没有对标
- **表现**：「国内领先」但没列对标公司。
- **为什么不行**：没有参照物的「领先」是自我评价，不是事实。
- **怎么改**：列 2-3 家可比公司 + 关键指标对比 + 数据来源和时点。

### A-3 商业模式说得很热闹，就是不说怎么赚钱
- **表现**：「打造 XX 平台，构建行业生态」——付费方是谁？收入怎么拆？
- **为什么不行**：空泛的平台叙事掩盖了商业实质，是典型的空洞描述。
- **怎么改**：紧接收入拆分表 + 付费主体 + 关键经营指标。

### A-4 替监管做判断
- **表现**：「公司完全符合科创板定位」——这是审核机关的判断，不是中介机构替客户下的结论。
- **为什么不行**：越界断言既有执业风险，也经不起审核质疑。
- **怎么改**：只给分析框架和对照依据，结论留给有权判断的主体确认。

### A-5 尽调事项一笔带过
- **表现**：股权代持、突击入股、对赌安排等敏感事项只写「已核查」没有过程。
- **为什么不行**：这些是审核必问项，「已核查」三个字撑不起核查责任。
- **怎么改**：按尽调清单逐项写明核查方式 + 结果 + 留痕位置。

### A-6 风险披露拣好的说
- **表现**：只列「市场竞争风险」这类通用风险，回避金额大、概率高的具体风险。
- **为什么不行**：风险披露的要求是按重要性完整列示，避重就轻本身就是问题。
- **怎么改**：按重要性排序，重大风险写透；诉讼处罚类按金额阈值完整列示。

### A-7 研发支出边界含糊
- **表现**：研究阶段和开发阶段的划分没有依据，资本化时点说不清。
- **为什么不行**：资本化直接调利润，是财务审核的重点穿透区。
- **怎么改**：写明开发阶段/研究阶段分界依据 + 同行业处理方式对比。

## 三、表述类（话不像投行说的）

### S-1 AI 写作腔
- **表现**：「值得注意的是」「综上所述」「赋能」「抓手」「底层逻辑」这类词高频出现。
- **为什么不行**：审阅人（监管、投资人、质量风控）对这些词高度敏感，一眼判定是机器稿。
- **怎么改**：跑脚本扫黑名单（`wordlist-ai-flavor.txt`），命中处改成平实的事实陈述；需要时配合去 AI 痕迹改写工具。

### S-2 形容词堆砌
- **表现**：「广阔的市场前景、强大的研发实力、优秀的客户资源」——三个形容词，零个数据。
- **为什么不行**：形容词是观点，数据才是事实；堆形容词等于什么都没说。
- **怎么改**：删形容词，换成「事实 + 数字 + 来源」。

### S-3 裸数字
- **表现**：数字后面没跟单位（「营收 11.2」），或没有时点。
- **为什么不行**：见数字五要素。
- **怎么改**：补全五要素；脚本可粗筛这类位置。

### S-4 绝对化用词
- **表现**：「行业领先」「全球首创」「绝对安全」「稳居第一」。
- **为什么不行**：没有第三方数据+来源撑腰的绝对化表述，是广告法和信息披露的红线。
- **怎么改**：删掉；确需保留的，补第三方数据 + 来源 + 时点（如「据 XX 报告，2024 年市占率行业第二」）。

### S-5 大段文字不消化
- **表现**：整页没有表格、没有分点，一段塞五六个意思。
- **为什么不行**：投行文档的读者是扫读的，不结构化的内容等于没写。
- **怎么改**：一段一个核心观点；并列关系用表格或分点；数据优先做表。

### S-6 主观代词露馅
- **表现**：「我认为」「笔者觉得」。
- **为什么不行**：个人口吻不符合机构文件的严肃性要求。
- **怎么改**：用「我们认为」或以机构名义表述；能去掉判断的直接去掉。

## 四、编造类（红线，命中即该段作废）

### X-1 编造数据、来源、主体
- **表现**：查无此报告的「据 XX 研究」、不存在的统计口径、虚构的公司名或人名。
- **处置**：不是修改的问题，该段整体作废重写。编造是投行文档的零容忍项。

### X-2 把「待补」当事实写
- **表现**：数据还没拿到，先用估计值写进正文且不标注。
- **处置**：所有未落实的数据必须显式标注「待补」并登记位置，交付前逐项清点。
