# 使用示例（examples.md）

> 最小可复现示例：输入样例 → 命令 → 期望输出。以下均为实测通过的真实输出（Python 3 标准库，零依赖）。

## 示例 1：反模式机械扫描（绝对化 / AI 痕迹 / 裸数字）

**输入样例** `demo.md`：

```
发行人营业收入达到30.2亿元，本产品独一无二，绝对不可能出现任何差错，市场占有率超过50%。
另：报告期各期收入分别为1.2亿元、1.5亿元、1.8亿元，呈持续上升趋势。
```

**命令**：

```bash
python scripts/check_gates.py demo.md
```

**期望输出**（实测）：

```
=== ibd-quality-gates 扫描报告：demo.md ===
扫描行数：2；命中：1（HIGH 1 / WARN 0 / INFO 0）
[HIGH] G2-绝对化 | L1 | 词:「独一无二」| 发行人营业收入达到30.2亿元，本产品独一无二...
---
提醒：HIGH=须改；WARN=带来源标注，人工确认；INFO=裸数字粗筛，多数为正常序号，请人工复核。
```

脚本只查机械项；语义项（来源/口径/论证）仍需按 `references/antipatterns.md` 人工核对。

## 示例 2：数值自洽核对（金额文本格式 / 一致性）

**输入样例** `demo.md`：

```
报告期内发行人营业收入为 12345.6 万元，净利润 1020.5 万元。
```

**命令**：

```bash
python scripts/check_data.py --input demo.md
```

**期望输出**（实测：5 位以上金额未加千分位 → 警告 3 条；报告落 `<输入>_数据核对报告.md`）：

```
=== 数值自洽核对：demo.md ===
  错误: ✅ 0
  警告: ⚠️ 3
  提示: ✅ 0
  → 报告已写入：demo_数据核对报告.md
```
