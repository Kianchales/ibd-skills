# ibd-life-manager

> 操作使用者自备的私人 markdown 库；库名与库根见 [library.config.json](references/library.config.json)。

## 💡 这是什么

使用者自备的私人 Obsidian 库（库名与库根见 [library.config.json](references/library.config.json)；OLM/PPV 系统）的操作规则 skill：**AI 工作日志记录铁律、待办写入三路径（Action 定稿）、新会话接续三入口、02 工作边界铁律**。

## ✨ 快速开始

```
新会话接续（按序读，路径相对库根）：
1. README.md                            库使用手册
2. 04 AI Work/工作日志/YYYY-MM-待办.md  最近做了什么（Grep 节行号 → Read 最近 5 节）
3. 04 AI Work/待办事项.md               还要做什么
```

## 🧩 核心能力

- **AI 工作日志**：一天一节（`## YYYY-MM-DD`），`### ✅ 已完成` / `### ⏳ 待办` 两段，任务行 = 标题+结论+标记；工作区 daily log 管过程、本日志管结果（职责分层）
- **待办写入三路径**：项目待办唯一写入点 = 项目文件夹 `待办事项.md`；团队任务 `<人名>.md` 仅统计视图 AI 不写；AI 待办 = `04 AI Work/工作日志/`
- **对话加待办**：「给<项目>加待办：…」触发，写完即止不跟踪
- **项目文件夹标准结构**：七件套模板（面板/待办/归档/工作进程/注意事项/纪要/资料），完结 01→03 平移
- **周报/月报起草**：`03 报告` 周报/月报的总结正文由 AI 起草 → 用户确认 → 落盘（日报不补建、不代写）
- **同步域管理（四域）**：把「同步」拆成**搬运**（归外部系统，本 skill 不实现）与**管理**（归本 skill）两层——四域＝AI 工作区／资料区／定期报告／项目区；**先判机**（纯实测确认主机或副机，依据 ＝ 库内 `04 AI Work/机器拓扑清单.md`）再按域裁定权限；`ai_scope` 五档粒度（不介入→只管结构→管写入→管汇总→管跟进），**逐档放开**

## 🚀 典型场景

- **新会话接续**：按序读「库手册 → 工作日志最近 5 节 → 待办事项」，先对齐上下文再干活
- **记 AI 工作日志**：每次实质工作后，从工作区 daily log（过程草稿）提炼结论追加到当月文件——一天一节、`### ✅ 已完成` / `### ⏳ 待办` 两段，任务行 = 标题+结论+标记
- **对话加待办**：说「给<项目>加待办：…」→ 写入项目文件夹 `待办事项.md`，写完即止、不跟踪
- **项目文件夹整理**：按七件套模板（面板/待办/归档/工作进程/注意事项/纪要/资料）建结构；完结时整个文件夹 01→03 平移

## 🔗 与生态内其他 skill 的分工

- `obsidian`：Obsidian CLI/直连通用操作；daily note 私人日记由本 skill 承载
- `02 工作/` 为用户业务跟踪区：**管辖档位以库内实例清单所载为准**（未放开时按默认起点 `structure`，该档不跟踪、不汇总），与 AI 日志互不干涉（档位可逐档放开，见 [domains.md](references/domains.md)）

## 🚀 从零建库

还没有库？本包附一份**从零建库引导**与**空白库骨架**——五步走完即可用：

1. 装 Obsidian（免费桌面端）
2. 建一个空文件夹作为库根（想多端同步就放在同步盘）
3. 装插件：必需 **Tasks**、**Dataview**；推荐 Periodic Notes / Templater / Buttons / Kanban（清单与配置见引导）
4. 把 `assets/starter-kit/` 全部内容复制进库根（保持目录结构）
5. 按验收清单自检（首页按钮能建日报、看板查询能渲染、接续能读到内容…）

完整步骤、插件配置与常见问题见 [bootstrap.md](references/bootstrap.md)。

## 📦 安装与依赖

拷贝至用户级技能目录。依赖：使用者的私人库本体（同步盘）、Obsidian Tasks/dataview 插件、`obsidian` skill；**尚无库者先按 [bootstrap.md](references/bootstrap.md) 建库（空白骨架在 `assets/starter-kit/`）**。
