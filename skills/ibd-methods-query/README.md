# ibd-methods-query

方法论库「检索域」skill——把「索引 → 定向读取 → 合成」固化为标准检索链路，按需只读命中条目，**绝不全文读库**。

## 💡 这是什么

写作/分析/问答要查方法论时走本 skill 的标准链路：问题拆解 → 索引定位 → 定向读取 → 合成输出。库被索引映射为「编号 → 域文件 + 行号」，单次读取仅约 20KB。

## ✨ 快速开始

```
「查XX问题怎么写」
→ S1 问题拆解（问题域编号 + 关键词）
→ S2 索引定位（速查表 → 条目编号 → 条目标题目录得「域文件 + 行号」）
→ S3 定向读取（Read offset/limit 只读命中条目）
→ S4 合成输出（写作素材 / 分析结论 / 引用清单）
```

## 🧩 核心能力

- **三层检索对象**：主库（各域条目）→ 行业版（合并版 + 单份细分版）→ 单案（范式文件）
- **三种输出形态**：回复写作素材（给 writer）/ 分析结论（给分析角色）/ 引用清单（交付门禁）
- **检索失败降级**：速查无匹配 → Grep 关键词 → 登记待沉淀（新方法论缺口）

## 🚀 典型场景

- **写反馈回复前**：查「这类问题以前怎么答得好」——按问题域定位条目，定向读取
- **分析 / 问答消费方法论**：把命中条目汇总为分析结论或写作素材
- **交付前引用清单**：条目编号 + 使用位置对照（引用自检）
- **库很大时避免全文读**：索引把库映射为「编号 → 域文件 + 行号」，单次读取仅约 20KB

## 🔗 与生态内其他 skill 的分工

- `ibd-methods-ops`：互补——ops 管生产+维护（写入侧），本 skill 管检索消费（读取侧）
- `ibd-doc-write`：供其可选调用（写作链路的查库环节）；write 无本 skill 时按内嵌流程运行

## 📦 安装与依赖

拷贝至用户级技能目录。依赖：

- **方法论库 `{METHODS_ROOT}`**（使用者自建，路径可配置，示例 `~/methods/`）及其索引资产（4 个文件：调用索引 / 条目标题目录 / 路由入口 / 编号登记表——由 `ibd-methods-ops` 的 `refresh_index.py` 生成）
- 工具仅内置 `Read` / `Grep`，零第三方依赖
