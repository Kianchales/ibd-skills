# ibd-methods-query

## 定位简介

方法论库的**检索域** skill：标准检索链路「问题拆解 → 索引定位 → 定向读取 → 合成」，按需只读命中条目，不全文读库。适配任何按库规范（见 `ibd-methods-ops` 的 methods-guide.md）组织的方法论库——索引资产为生成物，由库维护脚本产出。

## 何时使用（触发）

- 写作/分析/问答需要查方法论：写反馈回复、招股书章节、尽调报告前的「问题拆解→查条目」
- 直接问「XX 问题怎么写 / 查 XX 问题方法论 / 查 XX 案 XX 问题的写法」
- 交付前的引用清单生成（引用来源对照）

## 边界与协作

- **与 ibd-methods-ops 互补**：ops 管「生产+维护」（蒸馏/体检/修复），本 skill 管「消费/检索」（查库）——同一方法论库（`{METHODS_ROOT}`）
- **供 ibd-doc-write 可选调用**：write 五步链路的查库环节可走本 skill 标准链路；write 无本 skill 时按其内嵌流程运行（功能等价，仅 token 效率差）
- **不承担生产**：检索发现方法论缺口只登记待沉淀清单，产出归 ops 蒸馏域

## 检索流程（S1-S4）

```
S1 问题拆解  问询问题/写作需求 → 问题域编号 + 关键词
S2 索引定位  方法论调用索引（速查表）→ 条目编号（主库域前缀 + 投行语言）；
             条目标题目录 → 域文件 + 行号；单案检索 → 单案索引对照表
S3 定向读取  按行号 Read offset/limit 只读命中条目（域文件/行业合并版/单案文件）
S4 合成输出  汇总命中条目 → 回复写作素材 / 分析结论 / 引用清单（编号+位置）
```

## 检索对象三层

| 层 | 范围 | 定位入口 |
|---|---|---|
| 1 主库 | 各域条目（财务/法律/行业/写作 + 投行语言），编号体系见库规范 | `{METHODS_ROOT}/方法论调用索引.md`（速查 + 全量映射） |
| 2 行业版 | 行业方法论合并版 + 单份细分版 | `{METHODS_ROOT}/行业方法论_<类名>.md` / `行业方法论_单份细分版/` |
| 3 单案 | 单案范式文件（`通用方法论_投行知识与写作范式_<案名>.md`） | 单案索引对照表 + 案文件本体 |

## 库接入适配（先读配置 · 按档位分派）

> 库为**开放后端**（本地目录 / Obsidian / 乐享 / ima / 任意 MCP 知识库 / 云文档……示例非穷举），配置由 `ibd-methods-ops` 管理（其安装目录下 `library.config.json`）。检索前先读该配置，按**能力档位**分派：

| 档位 | 检索方式 | 说明 |
|---|---|---|
| **A · 文件型**（本地/Obsidian/同步盘等） | 索引定位 → 行号定向读（Read offset/limit / Grep） | 全能力：渐进披露完整（token 最优） |
| **B · 检索型**（云知识库连接器，如乐享、ima 等） | 连接器搜索（关键词/语义）→ 拉取条目全文 | 无行号定位；先搜再拉，避免整库载入 |

- 配置缺失时：提示用户先在 `ibd-methods-ops` 完成「库配置」（四问引导），再走检索
- B 档检索：优先关键词精确检索，命中不足再用语义检索；拉取条目后按「编号 + 出处」输出（编号体系见库规范）

## 依赖与工具

- **工具**：`Read`（定向读取 offset/limit）+ `Grep`（索引关键词搜索）——内置，零外部依赖
- **索引资产**：`{METHODS_ROOT}` 下 4 个文件（见下表）；由库维护脚本生成（`ibd-methods-ops` ≥1.5.0 的 `refresh_index.py` 一键刷新）；库接入配置亦由 ops 管理（`library.config.json`）
- 无第三方依赖、无脚本、无输出资产（纯检索流程 + 文档）

## 索引资产（定向读取定位）

> 路径基准：`{METHODS_ROOT}` = 你的方法论库根目录（路径可配置，示例 `~/methods/`）；下表路径均为其下相对路径。本 skill 不携带索引资产（使用者自建，由 ops 脚本生成）。

| 资产 | 路径 | 作用 |
|---|---|---|
| 方法论调用索引 | `方法论调用索引.md` | 问题域速查表（Q1-QN）+ 全量映射（编号 → 问题域） |
| 条目标题目录 | `方法论_条目标题目录.md` | 编号 → 域文件 + 行号（Read offset/limit 用） |
| 路由入口 | `通用方法论_最终版.md` | 域路由表（薄壳） |
| 编号登记表 | `编号登记表.md` | 主库 + 单案编号总表 |

## 输出形态

1. **回复写作素材**：命中条目编号 + 核心规则 + 本案实证 + 套用句式（给 writer）
2. **分析结论**：命中条目汇总 → 问题覆盖度 + 缺口（给分析角色）
3. **引用清单**：编号 + 使用位置对照表（交付门禁）

## 关键纪律

- **绝不全文读库**：索引/目录已把库映射为「编号 → 行号」，一律定向 Read
- **跨体系路由**：主库编号（域-族-序）与单案编号（含案号）形态不同，不混用
- **编号是身份**：检索到的条目编号即引用编号，不另造
- **检索失败降级**：速查无匹配 → 关键词搜 `方法论调用索引.md`/`方法论_条目标题目录.md`（Grep）→ 仍无 → 登记待沉淀（新方法论缺口）
