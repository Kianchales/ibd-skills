# 方法论检索链路（retrieval-chain.md）

> ibd-methods-query 的检索细节单一事实源。SKILL.md 是薄壳路由，本文件按需读取。
> 路径基准：`{METHODS_ROOT}` = 方法论库根；`methods/…` 为其下相对路径。**`state/` 不在其中**——流程状态台账（单案索引对照表 / 待补学清单 / 体检计数 / 回写清单指针）在**工作区根**（`{METHODS_ROOT}` 的上一级，与 `app/`、`tasks/`、`cases_md/`、`archive/` 同级）。

## 1. S1 问题拆解

**目标**：把问询问题/写作需求映射到 28Q 问题域 + 关键词。

- 问询函问题 → 直接按「常见问询问题类型速查表」（`方法论调用索引.md` §一）匹配 Q1-Q28
- 复合问题 → 拆成多个单域子问题，每个子问题独立查 Q
- 关键词补充：收入/毛利/存货/对赌/股权/募投/产能/市占率/研发/现金流/关联交易…

**28Q 速查表概览**（Q1-Q16 示例，全量见调用索引）：

| Q | 问题域 |
|---|---|
| Q1 | 收入确认时点与模式 |
| Q2 | 收入真实性核查（境外/第三方/对账/经销穿透） |
| Q3 | 毛利率与盈利质量 |
| Q4 | 成本与采购（原材料/客供料/副产品/返利折让） |
| Q5 | 存货 |
| Q6 | 应收账款/票据/保理 |
| Q7 | 经营现金流 |
| Q8 | 研发（费用率/资本化/样机） |
| Q9 | 产能与产能利用率 |
| Q10 | 募投项目（必要性/消化/测算/环评用地） |
| Q11 | 客户集中度与稳定性 |
| Q12 | 关联交易 |
| Q13 | 对赌与特殊投资条款 |
| Q14 | 实控人/控制权 |
| Q15 | 股权代持/出资/历史沿革 |
| Q16 | 股份支付/员工持股/股权激励 |
| … | （Q17-Q28 见调用索引全量） |

## 2. S2 索引定位

**主库检索**（优先）：
1. `方法论调用索引.md` §一速查表 → 该 Q 的核心推荐条目（F/L/I/S + WL/PL）
2. `方法论调用索引.md` §二全量映射 → 该 Q 下全部条目（精确）
3. `方法论_条目标题目录.md` → 每条目的**域文件（或卷文件）+ 行号**

**语言专项检索**（措辞/句式/段落结构类问题）：
- **W 系列**（投行语言句式，357 条）→ 索引/目录「附：W 系列」→ `methods/投行语言专项_W系列.md`（按行号直读）
- **P 系列**（招股书语言范式，442 条）→「附：P 系列」→ `methods/分卷/投行语言专项_P系列_卷N.md`（**先定卷、再按行号读**）
- **体例域批次卷** → `methods/分卷/通用方法论_体例域_卷N.md`

**行业版检索**：行业问题（市场空间/竞争格局/市占率/技术）→ `methods/行业方法论_<类名>.md`——**扁平文件，无「合并版」子目录**（如 `行业方法论_半导体制造.md`、`行业方法论_智能装备.md`）→ 按行号直读；单一公司行业研究在 `methods/行业方法论_单份细分版/`。

**单案检索**（按案）：
1. `state/单案索引对照表.md`（**工作区根**）→ 规范案名 → 案号（**4 位 AN**）
2. `methods/单案/通用方法论_投行知识与写作范式_<规范案名>.md` → 域分区（财务/法律/行业/写作）→ 该案对应条目（`域-AN{案号4位}-序号`）
3. 无单案文件的案（现 **22 案**，AN0054–AN0075）→ 按对照表路由到 `cases_md/`（蒸馏材料镜像，已入 git）；案名对不上时先用 `方法论_案名规范表.md` 规范化

**跨体系路由规则**：
- 主库编号 `F-010001` = 域-族号2位-族内4位（v37 主库体系）
- 单案编号 `F-AN0015-01` = 域-AN案号4位-序号（案号前缀 AN，与国标行业分类码 C39/C3985 天然隔离）
- 写作域单案 `W-AN0016-L01` = W-AN案号-维度（L=法律/I=行业/F=财务/A-D=遣词口径结构论证）
- 语言专项 `WL-150001`（回复句式）／`PL-010001`（招股书范式）= 语言层族号体系
- 形态不同，**禁止混用**；主库引用单案统一 `域-AN{案号4位}-序号`
- **案号不回收、不自编**：由主理人在批登记表顺序分配（下批自 **AN0076**），现行号段见 `state/单案索引对照表.md`

## 3. S3 定向读取

**方法**：`Read` 工具 offset/limit 只读命中条目区间（条目标题目录给出行号）。

```
例：读财务域 F-010001（外销收入确认时点论证）
  条目标题目录 → 通用方法论_财务域.md L12（行号以条目标题目录实时查询为准）
  Read methods/通用方法论_财务域.md offset=12 limit=30
```

**要点**：
- 每条目 3-4 段（标题/方法论要点/实证/适用场景），limit 30 行够；字段名随层——跨案层 `实证`／单案层 `本案实证`（契约见 ops 的 `entry-contract.md`）
- 多条目命中 → 按优先级顺序读取（速查表「按优先级」列）
- **分卷类目**（P 系列 / 体例域批次）：索引给的是「卷文件 + 行号」→ **先定卷、再按行号读该卷**；不读入口、不读主域文件全文
- 需要案级写法 → 读单案文件对应条目（更细的原文实证/句式模板）
- **行号漂移自检**：怀疑索引过期时跑 ops 的 `check_index_locator.py --methods-root <工作区根>` 抽查
- 不整文件读，不整段复制——取「规则+实证+适用」三件套

## 4. S4 合成输出

**回复写作素材**（给 writer）：
```
命中条目：
- F-010001 外销收入确认时点论证（规则：贸易条款挂钩＋控制权双维论证＋同行佐证）
- WL-150001 问询回复双段式结构（句法：…）
- F-AN0015-01 沛城案例（本案实证：寄售领用/对账时点＋客户管理机制披露）
→ 套用建议：先双段式结构 → 收入确认时点按 F-010001 论证 → 引用沛城案级句式
```

**G4 引用清单**（交付门禁）：编号 + 使用位置对照表（问询问题类型→方法论条目→使用位置）。

## 5. 检索失败降级（三态）

1. 28Q 无匹配 → Grep `方法论调用索引.md` + `条目标题目录.md` 关键词搜索
2. 仍无 → 确认是否新方法论缺口 → 登记蒸馏待办（下轮蒸馏补）
3. 单案查不到 → 按 `state/单案索引对照表.md` 查「无单案文件案」（现 22 案，AN0054–AN0075）→ 路由到 `cases_md/`（无范式文件）；案名先经 `方法论_案名规范表.md` 规范化

**冷启动（库未建 / `library.config.json` 缺失）→ 冷启动引导档**：

- 判定：读配置失败 / `{METHODS_ROOT}` 目录不存在或无任何库文件 → 视为库未建（首次使用正常态）
- 动作：① 向用户确认库根路径（默认建议 `~/methods/`）→ ② 按 methods-guide.md「起步结构（4 文件）」+「§九 空库起步模板」建骨架 → ③ 写最小 `library.config.json`（A 档默认；schema 单一事实源在 ops，后续 ops 四问引导自动认账）→ ④ 本次检索输出「无命中 + 待沉淀登记」+ 指出两条起步路径（methods-guide §五）
- 边界：只建结构骨架、不造方法论内容——蒸馏生产归 `ibd-methods-ops`

## 7. 检索对象四层（定位入口详表）

| 层 | 范围 | 定位入口 |
|---|---|---|
| 1 主库域条文 | 通用域条目（财务/法律/行业/体例），编号 `域-族号2位-族内4位` | `{METHODS_ROOT}/方法论调用索引.md`（§一速查 + §二全量映射） |
| 2 语言专项 | 投行语言句式（W 系列 357 条）与招股书语言范式（P 系列 442 条）；P 系列与体例域批次正文**已外置分卷** | 索引/目录的「**附：W 系列**」「**附：P 系列**」章节 → `投行语言专项_W系列.md`、`分卷/` |
| 3 行业版 | 行业方法论**扁平合并文件**（按类名，非子目录）＋ 单份细分版 | `行业方法论_<类名>.md`（如 `行业方法论_半导体制造.md`）／`行业方法论_单份细分版/` |
| 4 单案 | 单案范式文件（`通用方法论_投行知识与写作范式_<规范案名>.md`） | `{METHODS_ROOT}/单案/`（2026-09-16 起归拢子目录）+ `state/单案索引对照表.md` |

- **两层根的区别**：`{METHODS_ROOT}` 是方法论库根（域文件/分卷/行业版/单案/notes/scripts/archive 在此）；`state/`（流程状态台账）在**工作区根**（`{METHODS_ROOT}` 的上一级，与 `app/`、`tasks/`、`cases_md/` 同级）——单案索引对照表按此定位
- **行业版无「合并版」子目录**：行业方法论为扁平文件，按类名直接 Read；细分研究进 `行业方法论_单份细分版/`

## 9. 输出形态（S4 出口详规）

1. **回复写作素材**：命中条目编号 + 核心规则 + 实证（字段名随层：跨案层 `实证`／单案层 `本案实证`）+ 套用句式（给 writer）——字段契约见 `ibd-methods-ops` 的 `entry-contract.md`
2. **分析结论**：命中条目汇总 → 问题覆盖度 + 缺口（给分析角色）
3. **引用清单**：编号 + 使用位置对照表（交付门禁）；引用案名一律用**证券简称**

## 10. 关键纪律（全文）

- **绝不全文读库**：索引/目录已把库映射为「编号 → 行号」，一律定向 Read
- **跨体系路由**：主库编号（`域-族号2位-族内4位`）与单案编号（`域-AN{4位}-序号`）形态不同，不混用；案号一律 4 位、集中分配、**不回收不自编**
- **案名一律用证券简称**：按案名检索或引用前先对照 `方法论_案名规范表.md`（已上市/挂牌取证券简称、在审取交易所项目页公司简称，别名映射见其表三），不自造写法
- **分卷读法**：P 系列与体例域批次正文已外置 `{METHODS_ROOT}/分卷/`，索引/目录给的是「卷文件 + 行号」→ 按行号直接读卷文件，**不往入口或主域文件追加或读全文**
- **编号是身份**：检索到的条目编号即引用编号，不另造
- **检索失败降级**：速查无匹配 → 关键词搜 `方法论调用索引.md`/`方法论_条目标题目录.md`（Grep）→ 仍无 → 登记待沉淀（新方法论缺口）
- **冷启动不报错**：库未建/配置缺失属首次使用正常态——走冷启动引导档（建骨架 + 登记缺口），不向用户抛裸读取失败

（降级三态与冷启动的**逐动作规程**见 [library-backend.md](library-backend.md) §2；本节只列纪律本身。）

## 11. 边界与协作（全文）

- **与 ibd-methods-ops 互补**：ops 管「生产+维护」（蒸馏/体检/修复），本 skill 管「消费/检索」（查库）——同一方法论库（`{METHODS_ROOT}`）
- **供 ibd-doc-write 可选调用**：write 五步链路的查库环节可走本 skill 标准链路；write 无本 skill 时按其内嵌流程运行（功能等价，仅 token 效率差）
- **不承担生产**：检索发现方法论缺口只登记待沉淀清单，产出归 ops 蒸馏域
