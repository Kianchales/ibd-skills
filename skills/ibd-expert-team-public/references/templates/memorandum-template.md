# 备忘录类写作模板（Memorandum Template · v2.2 暂缓包 C）

> 用途：撰写内部备忘录（尽调备忘录 / 立项备忘录 / 内核备忘录 / 合规备忘录 / 估值备忘录 / 交易备忘录）。
> 样式：**000-009 样式体系**（以 `references/templates` 为模板文件填充正文，保留其 styles.xml）。
> 触发：用户要求"写备忘录/尽调备忘录/立项备忘录/内核备忘录/合规备忘录/估值备忘录"。
> 门禁：交付前过 交付自检 10 条 + 质量自评 ≥25 分 + G1-G3（质量门）。

---

## 一、使用前必做（法规与案例检索）

> **备忘录类模板的核心差异 = 先查法规与案例，再动笔**。每个判断必须有法规/案例依据，禁止凭经验臆断。

**检索顺序**：
1. **法规库**：法研（fyopen-lawsearch）/ 北大法宝（pkulaw）→ 核对最新有效版本（文号+条款+生效状态）
2. **乐享知识库案例**：`search_kb_search keyword=「[主题]」` → 同类项目处理方式 / 反馈回复 / 审核关注点
3. **Wind 反馈回复**（配额内直接使用）：`get_company_announcements` query=「公司,审核问询回复,2026」→ 同类问询与回复范式
4. **公开源**：交易所官网、证监会公告（WebSearch 兜底）

**检索留痕**：每个引用标 文号/条款/案例名/来源链接；检索不到的标"待补"并说明需要什么。

---

## 二、结构骨架（按备忘录类型选）

> **序号层级映射（2026-08-13 用户裁定）**：备忘录**无自定义一级编号**，一级标题直接用"一、"，其后按 `一、→（一）→1、→（1）→1）→①→A、→a、` 顺延（不跳级、不混用）。样式映射：002→"一、"、003→"（一）"、004→"1、"、005→"（1）"、006→"1）"、007→"①"。

### A. 通用备忘录（八段）
```
备忘录头：致 / 自 / 日期 / 事由 / 密级
一、背景与目的
二、关键事实与数据
三、法律法规与案例检索
四、分析与判断
五、风险提示
六、结论与建议
七、待办事项（如需）
附：数据来源与口径说明
```

### B. 尽调备忘录（专项）
调查范围与方法 → 公司基本情况 → 业务与技术 → 财务与会计 → 法律与合规 → 风险因素 → 调查结论与建议

### C. 立项/内核备忘录
项目概况 → 行业与市场 → 财务要点 → 法律要点 → 审核关注点预判 → 保荐风险提示 → 立项/内核建议

### D. 合规备忘录
合规问题描述 → 适用法规（文号+条款+生效状态）→ 案例检索（同类处理/处罚案例）→ 合规判断（框架性）→ 建议（由保代/律师最终确认）

## 三、写作范式要点（强制规范）

1. **法规/案例先行**：每个判断有法规或案例依据；监管判断只提供框架，最终由保代/律师确认。
2. **结论前置**：开头给核心结论（1-2 句），正文展开依据。
3. **事实与观点分离**：事实（客观+来源）与观点（分析+依据）分区呈现。
4. **数字五要素**：每个数字含 单位+时点+来源+精度+可比口径；缺失标"待补"。
5. **表格格式**（如有表格）：按「表格模板.docx」规范（2026-08-13 用户裁定）——上下 1.5pt/内部 0.5pt 黑色实线、左右不加框线；5号宋体+Times New Roman；单元格垂直居中；标题行加粗居中+多行标题行跨页重复；前几列居中、会计数字居右、"是/否/不适用"或性质介绍类居中；合计行加粗。
6. **风险提示充分**：结论的相反情境必须披露。
7. **中性客观**：禁止绝对化/营销化；内部备忘录用"我们建议/本所未见"等中性表述。
8. **密级与脱敏**：涉及未公开信息标注密级；客户/供应商/在研项目代号脱敏。

---

## 四、撰写后必做（自查 + 门禁）

1. 法规可溯源：每个法规引用有文号+条款+生效状态
2. 案例支撑：关键判断有案例/反馈参考
3. 数据可溯源：数字五要素齐全
4. 结论前置：开头有核心结论
5. 风险披露：结论的相反情境已披露
6. 走 交付自检 10 条 + 质量自评 ≥25 + G1-G3

---

## 五、禁止事项

- ❌ 不查法规/案例直接写判断（备忘录类核心纪律）
- ❌ 越界替客户/监管做定论（R4）
- ❌ 编造数据/案例/处罚记录（R1）
- ❌ 泄漏未脱敏敏感信息（客户名/供应商名/在研代号）
