# 招股书章节写作模板（Prospectus Section Template · v2.2 暂缓包 C）

> 用途：撰写 A 股招股书核心章节（业务与技术 / 管理层讨论与分析 / 风险因素 / 财务会计信息）。
> 样式：**000-009 样式体系**（以 `references/templates` 为模板文件填充正文，保留其 styles.xml）。
> 触发：用户要求"写招股书/招股说明书章节/业务与技术/MD&A/风险因素/财务会计信息"。
> 门禁：交付前过 交付自检 10 条 + 质量自评 ≥25 分 + G1-G3（质量门）。

## 二、结构骨架（按章节选）

> **序号层级映射（2026-08-13 用户裁定）**：招股书一级标题为自定义编号"第一节 XXX"，**序号从二级开始**。

| 样式 | 层级 | 序号格式 | 示例 |
|------|------|---------|------|
| 001（0011） | 一级 | 章节编号（自定义） | "第一节 发行人基本情况" |
| 002 | 二级 | `一、` | "一、主营业务与产品" |
| 003 | 三级 | `（一）` | "（一）行业基本情况" |
| 004 | 四级 | `1、` | "1、市场规模" |
| 005 | 五级 | `（1）` | "（1）竞争格局" |
| 006 | 六级 | `1）` | "1）可比公司" |
| 007 | 七级 | `①` | "① 收入构成" |

> 规则：二级起严格按 `一、→（一）→1、→（1）→1）→①→A、→a、` 顺延，不跳级、不混用。

### A. 业务与技术（八大节）
1. 主营业务与产品 → 2. 行业基本情况 → 3. 技术与研发 → 4. 采购与供应 → 5. 生产与运营 → 6. 销售与客户 → 7. 主要资产与资质 → 8. 风险因素（按重要性排序）

### B. 管理层讨论与分析（MD&A，四段逻辑链）
1. 经营业绩分拆（收入→成本→毛利→费用→利润）→ 2. 资产负债分析（货币资金/应收/存货/商誉）→ 3. 现金流分析（经营/投资/筹资，与净利润差异归因）→ 4. 重大事项与前瞻（预测必附条件与风险）

### C. 风险因素（六类，按重要性降序）
经营风险 → 财务风险 → 行业与市场风险 → 法律与合规风险 → 募集资金运用风险 → 其他风险
每条含四要素：风险描述 → 发生背景 → 对本公司影响（量化）→ 已/拟采取措施

### D. 财务会计信息
财务报表（照搬审计报告）→ 主要会计政策（收入确认/研发资本化/坏账/存货/股份支付/商誉）→ 关键财务指标 → 可比公司选择（注明标准+代码+可比性）

## 三、写作范式要点（从范例提炼的强制规范）

1. **中性客观**：禁止绝对化/营销化（质量宪法 N1-N2）；监管判断只提供框架（N7）。
2. **数字五要素**：每个数字含 单位+时点+来源+精度+可比口径；缺失标"待补"。
3. **数字前置/重点前置**：段落首句给核心数据，不做铺垫；长句拆短（≤60 字）。
4. **口径显性**：指标首次出现给定义+公式（如 ARR/GMV/毛利率口径）。
5. **风险与前瞻并列**：任何预测/增长/估值后紧跟条件+量化影响+风险因素索引。
6. **表格优先**：收入构成/客户集中度/研发投入/风险因素等优先表格；表前单位行（008）、表后备注（009）。**表格格式按「表格模板.docx」规范**（2026-08-13 用户裁定）：上下 1.5pt/内部 0.5pt 黑色实线、左右不加框线；5号宋体+Times New Roman；单元格垂直居中；标题行加粗居中+多行标题行跨页重复；前几列居中、会计数字居右、"是/否/不适用"或性质介绍类居中；合计行加粗。
7. **与审计报告一致**：财务会计信息数字不得改写审计报告原文。

---

## 四、撰写后必做（每节自查 5 项 + 门禁）

1. 量化：每个观点有无具体数字支撑
2. 单位/时点/来源：数字五要素齐全
3. 绝对化：黑名单词全局搜索=0
4. 口径一致：与范例/审计报告/前后章节一致
5. 风险：前瞻表述均附风险提示
6. 走 交付自检 10 条 + 质量自评 ≥25 + G1-G3
