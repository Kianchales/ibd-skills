# 问询回复写作模板（Inquiry Response Template · v2.2 暂缓包 C）

> 用途：撰写审核问询回复（发行人及保荐机构回复，对应 8-1 系列）。
> 样式：**反馈回复样式模板**（`references/templates`，2026-08-13 用户上传，000-009 反馈回复版 + 0011/001 黑体问题样式）——以该 docx 为模板文件填充正文，保留其 styles.xml；完整样式定义见下文「〇、样式体系」。
> 触发：用户要求"写审核问询回复/反馈回复/问询函回复/落实函回复"。
> 门禁：交付前过 交付自检 10 条 + 质量自评 ≥25 分 + G1-G3（质量门）。
> ⚠️ 范围：仅发行人及保荐机构回复（标题「{公司}:{公司}及{保荐机构}关于…」）。**会计师回复意见（8-2）/法律意见书不采集、不撰写**（用户裁定）。

## 〇、样式体系（反馈回复 000-009 版 · 2026-08-13 用户上传样式模板）

> 本套样式与「报告模板.docx」的 000-009 招股书版同源，但针对反馈回复场景差异化定制：
> **① 新增「001 问题正文」黑体样式**（引用审核问询函问题原文，区别于正文宋体）；**② 0011 一级标题无分页前**（回复文档不分章节页）；**③ 002-006 二级~六级标题全部加粗**（非黑体标题）。

**段落样式使用范式**（document.xml 实证，逐题循环）：
```
[0011] 问题1.XXXX                    ← 问题编号标题（黑体，两端对齐，无分页前）
[001]  问题正文内容，内含多个明细问题   ← 引用问询函问题原文（黑体，首行缩进480）
[000]  【回复】                       ← 回复开始（宋体正文）
[002]  一、明细问题1                  ← 明细问题标题（加粗）
[000]  回复正文内容…                  ← 回复正文（宋体正文，数字五要素+表格支撑）
[002]  二、明细问题2                  ← …
[0011] 问题2.XXXX                    ← 下一题循环
```

> ⚠️ 与报告模板（000-009 招股书版）差异对照：**001 为反馈回复专用问题正文（黑体）**；0011 一级标题**无分页前**；002/003 由"黑体不加粗"改为"默认字体加粗"。其余（000 正文/008 单位/009 备注/表格样式）一致。

**序号层级映射（2026-08-13 用户裁定）**：反馈回复一级标题为自定义编号"问题1.XXX"，**序号从二级开始**。

| 样式 | 层级 | 序号格式 | 示例 |
|------|------|---------|------|
| 0011 | 一级 | 问题编号（自定义） | "问题1.收入确认" |
| 001 | 问题正文 | （引用问询函原文，不编号） | — |
| 002 | 二级 | `一、` | "一、明细问题1" |
| 003 | 三级 | `（一）` | "（一）分产品收入" |
| 004 | 四级 | `1、` | "1、销售模式" |
| 005 | 五级 | `（1）` | "（1）直销模式" |
| 006 | 六级 | `1）` | "1）验收时点" |
| 007 | 七级 | `①` | "① 收入确认依据" |

> 规则：二级起严格按 `一、→（一）→1、→（1）→1）→①→A、→a、` 顺延，不跳级、不混用（禁止"1、"与"1."混用）。

### ⚠️ 序号前缀≠标题：正文与标题的区分规则（2026-08-13 用户裁定，必须按文档前后结构判断）

> **"1、""（1）""1）""①"开头的段落，可能是标题也可能是正文**——不能只看序号就标标题，**必须根据文档前后结构判断**（超聚变复刻实证：005 样式 4 段"（1）全球算力基础设施市场规模快速提升。…"实为正文、007 样式 4 段"①工程化壁垒：…"实为正文，均已改回 000）。

**正文模式（序号开头但为正文，用 000 样式）**：
- **引导句 + 列举正文**：前文有引导句（"呈现以下特征：""来源于以下几个因素：""包括：""如下："等），序号项是**完整句子 + 多句论述**（通常 >40 字），段落后**无独立正文展开**
- 实证："并呈现以下特征：（1）全球算力基础设施市场规模快速提升。人工智能、大模型等…"（列举正文）；"液冷先发优势的持续性来源于四个相互强化的壁垒：①工程化壁垒：整机柜液冷产品累计交付超10万节点，积累了丰富的…"（列举正文）

**标题模式（序号开头且为标题，用 005/006/007 样式）**：
- 序号项是**简短短语/冒号式标题**（通常 ≤40 字），**段落后有独立正文段落展开**
- 实证："（1）算力基础设施层：以数据中心服务器为核心的完整产品布局" + 后跟正文段落

**判断步骤**：① 看序号段落前文是否有引导句 → 有则倾向正文；② 看序号段落自身长度与句式 → 长句完整论述=正文，短短语=标题；③ 看段落后是否有独立正文展开 → 有展开=标题。三者综合判定，不能只看序号。

## 三、写作范式要点（强制规范）

1. **逐题对应**：不得漏题/串题/合并答题；每题用 0011 问题标题 + 001 问题正文（黑体）引用问询函问题原文后作答。
2. **回复四段式**：问题概述 → 事实与现状 → 分析 → 结论。结论必须明确（"是/否/不存在/已整改"），不回避。
3. **事实先行**：先用数据/事实回答，再做分析；监管问什么答什么，不扩题。
4. **样式使用范式**：严格按「〇、样式体系」段落范式——0011 问题标题（黑体，无分页前）→ 001 问题正文（黑体）→ 000 正文"【回复】"→ 002 明细标题（加粗）→ 000 回复正文；禁止把问题正文写成正文宋体或楷体。
5. **法规依据**：涉及合规判断引用具体法规（文号+条款+生效状态），并提示"最终以保荐机构/律师确认为准"。
6. **数字五要素**：每个数字含 单位+时点+来源+精度+可比口径；缺失标"待补"。
7. **中性客观**：禁止绝对化/营销化；风险如实披露，不隐瞒。
8. **表格优先**：数据支撑用表格（表头加粗、表前单位行 008、表后备注 009）。**表格格式按「表格模板.docx」规范**（2026-08-13 用户裁定）：上下 1.5pt/内部 0.5pt 黑色实线、左右不加框线；5号宋体+Times New Roman；单元格垂直居中；标题行加粗居中+多行标题行跨页重复；前几列居中、会计数字居右、"是/否/不适用"或性质介绍类居中；合计行加粗。
9. **轮次标识**：命名 `[板块]_[简称]_审核问询回复_第X轮_YYYYMMDD`（无轮次默认第 1 轮）。

## 四、撰写后必做（自查 + 门禁）

1. 逐题核对：问询函所有问题均有回复（无漏题）
2. 结论明确：每题回复有明确结论（不悬而未决）
3. 数据可溯源：数字五要素齐全
4. 法规准确：引用法规最新有效
5. 绝对化清零：黑名单词搜索=0
6. 走 交付自检 10 条 + 质量自评 ≥25 + G1-G3
