## 批次增量候选段归位规程（2026-09-23 · 五文件实证固化）

**场景**：`30_行业版/*.md` 尾部「`## 批次增量：…`」段的候选条目（旧体系 S6b 分流产物），按新体系归位到 `I-CL{类号}-{序}` 共通条目与子行业节。

**四步**：

1. **普查 —— 必须「从目标侧全量反推」**：扫**全部** `###`/`####` 级标题并人工抽验，**禁用形态白名单**。候选标题形态多样（`候选 N：`／`建议 X｜`／`增量 N｜`／`A1【…】`／`【XX】候选 N：`），用单一形态匹配**必漏**（**I-0086** 实证：漏 3 段 31 条）。
2. **分流判据**：跨案可迁移的**写法／论证范式** → 落 `I-CL` 共通条目；**行业事实骨架／案级定位** → 并入子行业节。候选段自带的「拟入位置／优先级」字段可参考，但**以内容性质为准**（实测多处字段与实际性质不符）。
3. **内容只搬不改**：要点／实证／关系**原样保留**，仅规范标题（去 `候选 N：`／`建议 X｜`／`增量 N｜`／`A1【…】` 前缀与尾部【标签】）与编号；段壳改「**附：批次增量处置记录**」（写清落号范围／子行业归入／条数／跨类互借登记目标）。
4. **落号前重算段内序号**：摘走共通条目后，**同段内剩余条目的序号会变**，WANT 表必须按「当前段内序」重算，否则取错条目（本批首跑即踩：钶锐锶取 6/10、三协取 2/12）。

**段边界注意**：段内本就有 `## 二、…` 级子标题（优先级表／案例对照／跨类互借），**不可当作段结束**；段边界只认下一个 `## 批次增量：`。

**结构巡检（同批必做）**：`I-CL` 条目**位置**不在门禁校验面内（`check_methods_health` 只校验编号唯一＋连续）⇒ 必须人工核「条目是否位于其所属章节范围内」。本批发现 3 文件 12 条串位（**I-0087**）：智能装备 `I-CL06-02/03/04` 落在子行业章尾｜电子材料 `I-CL07-01~09` 落在「第二部分」下｜汽车电子链 `I-CL04-01~05` 落在子行业章内。

**段壳命名归一**：副本剔除后仅剩「跨案对照 ＋ 编号索引」的段，标题应由 `## 批次增量：XX（AN00xx）` 改为 **`## 跨案对照与编号索引（XX · AN00xx）`**（避免与未归位段混形）。

**验收**：候选标题全库扫 **0 处** ＋ `I-CL` 序号连续 ＋ 五门（health／locator／entry_contract／幂等／旧编号残留）。

### 附：主库候选段「转正入正式章」（2026-09-23 · 四文件 61 条实证固化）

**适用**：主库（`10_跨案域/` 法律·行业·财务域 ＋ `20_语言专项/`）尾部的「`## 批次增量：`」候选条目明细段 —— 每条带「拟编号」或已是规范条目体例，但**正式章查无该条目**。

**三步**：

1. **核验（必须先做）**：① 全库编号重号扫描 ② **族内 max 复核**（候选编号须 > 正式章同族 max，防撞号）③ 抽样验「编号在正式章 0 处／候选段 1 处」。
2. **转换**：① 删元字段（`拟编号`／`条目标题`）② 标题加**批次尾注**（如 `【2026-09-12 批次·通用】`）③ 按**时间序追加至正式章末尾** —— 主库为**扁平追加式**（无族分组，不按族插），前加 `> **补入（日期）**：…` 溯源注；插入点前后**须留空行**（否则引用块被折入上一条列表）。
3. **段壳**：原段改「附：批次增量处置记录（日期 · 转正入章）」，逐段记**条数与编号区间**。

**形态判据**：主库条目**编号后可能无空格**（`### L-010001标题`）⇒ 摘取正则勿强求 `\s+`；候选项一般带空格，但仍以**计数对账**（摘出数 == 勘察数）为准。

**前缀归类陷阱**：按 `m.group(1)[0]` 归族会把 `WL-` 与 `W-` 并成同一 key ⇒ 误判「双前缀混用」。**多字符前缀必须整体比对**。

**平台边界**：`50_分卷/` 的 `## 批次增量：…` 是**卷的批次容器标题**（卷按「蒸馏只追加不重排」外置、切线＝批次边界），属**既有架构特征**，不属本规程范围。

## 结构变更连带同步清单（2026-09-23 立 · 撤除载体实证）

> **适用**：库内载体的**改名／撤除／新增**（目录、文件名、文件数、护栏目数）—— 变更本身只是一半，**引用面才是漂移源**。
> **实证**：`30_行业版/单份细分版/` 2026-09-23 撤除后，**旧 automation 提示词仍有 4 处硬引用** ⇒ 无人值守运行会把已撤载体重建（护栏第 16 项能拦住重建，但**拦不住提示词里的路径描述本身**）。

**必查五面（缺一即漏）**：

| # | 面 | 检查方式 |
|---|---|---|
| 1 | **库内其它文件** | 全库 grep 旧名／旧路径（排除 `_generated`／`archive`／`60_notes` 沿革） |
| 2 | **skill 包**（多个包） | `<skills 根>/*/` 全 grep（`references/` ＋ `SKILL.md` ＋ `README.md`） |
| 3 | **automation 提示词** | `automation_update` **逐条 view** 全 6 条 → grep 旧名／旧路径／护栏目数（**不能只查相关那一条**：本次全扫发现只有 1/6 条需改，但不扫不知道） |
| 4 | **库内元文件与 state** | `state/*.md`（如 `维护体检计数.md` 写死的护栏目数）、`methods/README.md`、各 `README` |
| 5 | **门禁常量** | `_lib/layout.py` 路径常量 ＋ 各 `check_*.py` 的判据常量（如 `RETIRED_DIRS`） |

**提示词复扫五判据**（改完 automation 后逐条核）：

1. **撤除载体**在提示词中每次出现须为**禁止式**（「不得重建」／「禁重建」／「⛔ 无…」）；
2. **文件改名**后提示词中只允许**新名**；
3. **护栏目数**须等于 `check_methods_health.py` docstring 写的项数；
4. 一切**写死数字**旁须有「**以 X 实测为准**」（防二次静默过期）；
5. **表／清单的职能描述**须与其**标题**一致（如案名表两表）。

**配套纪律**：清账（撤除／改名）与护栏**成对做** —— 撤除载体须登记 `check_methods_health.py` 的 `RETIRED_DIRS`（第 16 项），改名须同步 `_lib/layout.py` 常量。**只改一边 = 留一个盲窗口**。

## 修复后验证清单（五步）

1. **dry-run 计划核对**：改动清单逐项确认（文件/行号/变换类型），无误再执行
2. **执行 + 备份**：备份先行；执行后立即验证
3. **结构/内容守恒断言**：行数守恒、diff 与计划精确一致、案维数据行零损伤
4. **重跑生成器**：`daily_distill.py refresh_index.py` 刷新生成物（目录/索引/入口）
5. **复跑护栏**：`check_methods_health.py` 0 ERROR + 幂等（重跑 0 计划/0 改动）

**全库编号迁移踩坑实录（案号 2→4 位化实证）**：⚠️ **工具已于 2026-09-23 退役** —— 原 `dryrun_case_migrate.py`／`migrate_case_no.py` 的路径形态停留在 2026-09-16 归拢**前**（无 `单案/` 前缀）⇒ 已失效，且与 `_lib/layout` 事实源脱钩；退役备份存会话审计目录。**下方踩坑结论仍有参考价值**（正则陷阱与四门复验流程适用于任何编号迁移）：① Python 正则 `\b` 把汉字算 `\w`，「见 L-C01-04」等紧贴中文的编号 token 会漏匹配——用 `(?<![0-9A-Za-z])` lookbehind 替代；② 迁移脚本必须**幂等或只跑一次**——无后缀约束的规则（如 `case_no: C(\d{1,2})`）重跑会把已 4 位案号二次补零（C0022→C000022），补救靠「位长分布终验」（统计全库 C 号位数分布，非 4 位逐个分类核验）+ 备份 diff；③ 表行 `| C34 |` 在行业方法论/单份细分版文件头是证监会行业分类码（GB/T4754），与案号同形——表行批量替换仅限对照/登记表，全库替换前必须先抽上下文分类（案号/国标码/类序号/占位符）；④ 先干跑报告 → 人工抽查计数 → 备份 → 执行 → 四门复验（token 残留 0 / 裸号分类扫 / 护栏 0 ERROR / 形态抽查）；⑤ **「同形不同义」的第三类**（2026-09-23 实测）：**主库编号 `I-{族2}{序4}` 与单案临时编号 `I-0000xx` 同为「`I-`＋6 位」** —— 不加段前缀限定必误伤（实测 dry-run 抓出海菲曼 9 行**主库编号**被误判为孤岛）。**判据：临时编号的第二段为 `00`，主库族号非 00** ⇒ 正则须写 `I-00\d{4}`；⑥ **范围写法必须先于单号替换** —— `I-000041~I-000044` 若先跑单号替换即被拆散成两半；且范围整体加标记（如 `旧 I-…`）后，单号正则须加 `(?<!旧 )(?<!~)` 双向断言防二次加标。
