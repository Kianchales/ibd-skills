## 2 实证项：四字段模型

**一个「实证项」＝ 四字段**，与排布无关 —— 机器解析只认字段，不认排版。

| 字段 | 必填 | 规范 |
|---|---|---|
| **案名** | ✅ | **规范案名 ＝ 证券简称**（与单案 `case` 字段一致，如「中科仪」；未上市／在审企业取申报文件中的公司简称）——**禁**公司全称、**禁**截断简称（略去通名后缀，如「微容」≠「微容科技」）、**禁**内部代号；不得省为「本案」。白名单与登记见 §2.1 |
| **案号** | 建议 | `AN00NN`；用于反查单案文件与回写清单 |
| **内容** | ✅ | 该案在本条主题下的**做法/数据/口径**（陈述式；禁评价性论证与形容词堆砌） |
| **来源** | ✅ | 见 §4；数字须与来源同源（同一句内禁跨来源混列） |

### 2.1 案名白名单（2026-09-19 用户裁定、落地 A4）

> 用户原话：「案名一定要用规范的案名，用证券简称。」

- **单一事实源**：库根《`方法论_案名规范表.md`》——表一（有单案文件）／表二（无单案文件的早期案）构成**白名单**；**表三 ＝ 别名映射（库内旧写法 → 规范案名）**，仅供回改脚本使用、**不入白名单**（别名一旦出现在标签里即报 ERROR）
- **核定口径**（2026-09-19 用户裁定「核定后修改，核定不了就删了那个简称」）：已上市／挂牌取**证券简称**；在审取**交易所 IPO 项目页「公司简称」字段**（当日实例：云深处→「云深处」、上海超硅→「上海超硅」、兆芯→「兆芯集成」、维安→「维安股份」、鑫华→「鑫华科技」、盛合→「盛合晶微」）；**核不出来的一律从表中删除**，不留悬案
- **适用范围**：库内**一切案名引用位**——实证标签 `**<案名>实证**`、并列清单 `（案名）`、`案名/案名`、族条目尾注 `（案名）`、表格「案名」列、正文指代
- **落地口径**：① 新案蒸馏**先登记规范案名**再写条目；② 白名单外案名引用 → A4 报 ERROR；③ 疑似截断（某白名单案名的真前缀）→ A4 报 ERROR 并给出规范名；④ 标签内写死案数（`三案实证`）→ A4 报 ERROR
- **校验**：`python scripts/check_entry_contract.py --methods-root <工作区根>`（A4；白名单为单案 `case` 字段 ＋ 登记表的并集）

## 3 三种排布（同一数据，三种呈现）

**排布 1 · 列表式（默认）** —— 适用：≥1 案且单案内容 ≤2 行
```
**实证**：
- 环能涡轮（AN0019）——FOB/CIF/CFR「孰晚」确认时点，占比 FOB 49.20%/EXW 22.18%（招 P152；问1 P176-177）
- 森峰激光（AN0021）——出口数据差异率 0.76%/1.02%/0.16%（问1 P216-217）
```

**排布 2 · 独立段式** —— 适用：单案增量 ≥3 行，或含子结构（多级列表/表）
```
**<案名>实证**：
- 细项一……（来源）
- 细项二……（来源）
```

**排布 3 · 表格式** —— 适用：≥3 案且需逐案列出处（列名固定）
```
**实证**：

| 案号 | 案名 | 实证 | 出处 |
|---|---|---|---|
| AN0042 | 三协电机 | …… | 招 P14；问1 P182 |
```

**排布 4 · 回写修订标记型（2026-09-23 登记）** —— 适用：中/中高重合**扩展**既有条目的适用场景（`apply_rewrite.py` 产出）
```
> **适用场景扩展 YYYY-MM-DD（<案名>）**：<扩展内容> —— <依据>（<来源>）
```
> **与「标签禁用第三条」的关系（勿混）**：本形态**含日期**，但**不受**禁日期约束——该禁令只管 `实证` 标签（`**实证**`／`**<案名>实证**`）；本形态属**修订留痕**（与 §S6「冲突修订留痕」同族），日期是其功能所需。此前它未登记于本节，属**契约册漏收**（2026-09-23 审计 C-04 补）。

## 4 来源标注契约

**格式**：`（来源简称 + 空格 + P + 页码）`；多来源用 `；`，页码区间用 `-`、并列用 `、`

| 简称 | 指代 |
|---|---|
| `招` | 招股说明书（默认最新版） |
| `招·注册稿` | 需区分版本时 |
| `问1` / `问2` | 第 1／2 轮问询回复 |
| `上会` | 上会稿 |
| `反馈` | 反馈意见回复 |
| `回复` | 问询回复**轮次无法判定时的兜底**（优先用 `问1`／`问2`；2026-09-19 分卷回改时登记） |

**四条规则**
1. **来源在前、页码在后** —— 禁 `（PAGE 195、220 招股书）` 这类颠倒形态
2. **同括号同源** —— 一个数字只挂它实际出处；跨来源须分别标注
3. 多来源用 `；` 分隔；`、` 只用于页码并列
4. 页间分隔统一 `、`（禁 `/P109` 形态）
5. **适用范围（2026-09-24 补）** —— 上述「页码区间用 `-`」**只作用于本节的规范格式**（**含空格＋`P` 分隔**，如 `问1 P348-352`）；**不适用于「层级-页码连写」形态** —— 连写时**层级分隔符与区间符必须异形**（层级用 `-`、页区间用 `~`，如 `8-1-63~65`），否则 `8-1-63~65` 与「三级层级＋单值」`8-1-2-13` 的**字符形态相同、不可判读**。规则全文见 `pending-rules` **R-0035** ＋ 方法论条目 `S-010117`。

### 4.1 非案例来源条目的「实证」位（2026-09-24 新增）

**触发**：条目**并非**由案例蒸馏而来，而是**外部规范**（国标／行业标准／法规条文／监管规则等）入编。

**规则**：

1. **字段名不变**——仍用 `实证`（不新造字段名，保校验白名单与跨册一致性）；
2. **内容改挂规范出处**——`实证` 位**以规范条款号承载、不挂案名**，写法：
   `- **实证（规范源＝<规范名＋编号，如 GB/T 15834—2011《标点符号用法》>，非案例）**：<§条款号：规则摘要>；<§条款号：…>`
3. **必标「非案例」**——使人一眼辨明证据类型，避免下游按案例检索；
4. **「适用场景」须落到投行文档**——给出该规范在申报文件／内部报告中的**具体落点**，不空谈规范本身。

**先例**：体例域卷 01-4 的 `S-010117`–`S-010119`（标点符号体例族，规范源 GB/T 15834—2011；2026-09-24 用户采纳）。

### 6.1 为什么单案层是「本案实证」、跨案层是「实证」

| 层 | 写法 | 依据 |
|---|---|---|
| 单案层（案例层） | `本案实证` | 「本案」**有指代对象**（即该案）；且该名是 §S4 冻结模板原文 |
| 跨案层（主库） | `**实证**` ／ `**<案名>实证**` | 规范**未定义跨案层字段**（§S4 只定义案例层条目模板）；主库是跨案层，「本案」无指代 ⇒ 由本契约定义 |

**实测分布（2026-09-19 · 三层实测，作为「异名是设计」的证据）**：

| 层 | `实证`（短式） | `本案实证`（全式） | 规范名 |
|---|---|---|---|
| 主库根（跨案层） | **224** | **0** | `实证` / `<案名>实证` |
| 单案层 `40_单案/` | 0 | **1,490** | `本案实证` |
| 产出层 `cases/*/产出_*` | 0 | **2,404** | `本案实证` |

**结论：跨层传递不需要"名字映射"表** —— 回写从单案取内容落为主库实证项，本就是**结构搬运**（案名成为字段、页码转契约格式），字段名差异不构成额外成本。（勘误：2026-09-19 首版契约曾把「两层异名需映射」列为"规范优先"的代价，属**夸大**，已纠正。）

## 7 回写产出三条硬约束

1. **只用 §3 的三种排布**，不得自创标签形态（历史反例：`**<案名>实证（YYYY-MM-DD 回写）**` 曾作为纪律写入 SKILL.md，已按 D2/D3 废止）
2. **标签内禁「回写」「日期」「批次」** —— 留痕走 CHANGELOG ＋ 蒸馏笔记
3. **落法与重合度挂钩**：高重合 → 并入既有实证区（字段同规，不改案例列表结构）；中高 → 排布 2 独立段（不并入、不改案数表述）
4. **实证标签的合法书写形态＝两种**（2026-09-23 修正 · 判 I-0088）：**行首** `**<案名>实证**` 与**顶层列表项** `- **<案名>实证**：`（后者是 `apply_rewrite.py` 回写的产出形态）。缩进列表项视为**内容小标题**、不入校验面。**机器受理面以 `scripts/check_entry_contract.py` 的 `BAN_LABEL` 为单一事实源——改形态必须同步该常量**（原实现只认行首 ⇒ 覆盖仅 18.4%、门禁假绿）。

**校验链**：落盘脚本 dry-run 阶段必跑 `scripts/check_entry_contract.py`（**0 ERROR 才允许 `--apply`**）；收尾必跑 `refresh_index.py` ＋ `check_methods_health.py`。

> **强制面提示（A3 的适用范围）**：§1 表列的「跨案层」指**内容规范**（四字段模型／三种排布／来源标注）全量适用；**字段名检查（A3）仅对单案层 `40_单案/` 强制** —— 跨案层（`10_跨案域/`）与分卷不受 A3 约束（跨案层扁平条目与分卷均自成字段体系）。这是**有意的分层强制面**，非漏检。
