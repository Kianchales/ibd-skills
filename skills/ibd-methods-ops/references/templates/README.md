## 用法

1. **整份复制**模板 → 改名为目标文件名（命名规则见 `methods-guide.md` §三 与各模板首注）。
2. 逐项替换 `<占位>`；**章标题不得改写** —— 门禁按此比对骨架。
3. 保留 `<!-- ANCHOR:xxx -->` 注释：它是**机器比对锚点**（`check_methods_health` 第 14 项）。
4. 落库后跑：`check_entry_contract.py` → `refresh_index.py` → `check_methods_health.py`。

## 维护

- 改本目录任一模板 ＝ **改骨架规范**（属规范变更）→ 记 `CHANGELOG`；若同时影响门禁判据，须同步 `check_methods_health.py` 的锚点常量。
- 模板与规则冲突时：**规则为准**（模板是规则的落地物）；先改规则册、再改模板。
