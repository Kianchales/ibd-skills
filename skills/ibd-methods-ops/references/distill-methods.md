## §S4 专家产出三段式规范

### 产出文件结构（模板冻结 · 2026-09-06 统一，历史两版见 `产出格式规范登记表`）
- 文件名：`产出_<维度>_<公司简称>蒸馏.md`（如 `产出_财务_某案例公司蒸馏.md`），存各案工作目录 `{METHODS_ROOT}/cases/板块_简称_日期/`
- **文件头标题**（第 1 行，模板冻结）：`# <persona>·<维度>蒸馏·<公司简称>（<板块>·<阶段>·<稿本日期>）`——如 `# 财务专家·财务蒸馏·某案例公司（板块·阶段·稿本日期）`；persona 固定=财务/法律/行业专家，**不写 C{NN} 开头、不写 agent id**；维度词=财务/法律/行业
- **元信息块**（标题下 blockquote `>`）：案 例（公司全称+板块+阶段，保荐/审计并列）→ 主营（一两行）→ 报告期（审计/审阅/预计口径）→ 文件（招股书稿本+各轮问询回复及日期）→ 口径提示（PAGE 编号对应阅读包 `===== PAGE N =====` 标记；金额单位；报告期口径）→ **`> 蒸馏人：{persona}（{agent_id}，IPO {维度}专家）｜YYYY-MM-DD`**（如 `财务专家（示例标识，IPO 财务专家）｜2026-09-06`）
- **正文三节标题锁定**（禁措辞变体/禁范围式括号/禁加括号计数以外的注记）：
  - `## 一、知识蒸馏（N 条）`
  - `## 二、写作范式（N 条）`
  - `## 三、亮点/风险提示`
- 条目一律 `###` h3 标题，**禁加粗条目（`**F-…**` 型）、禁四级标题条目**（`####` 仅供 S5 writer 落库文件使用）

### 知识蒸馏条目（每条 5 要素）
| 要素 | 要求 |
|------|------|
| 标题 | `### <域>-AN<案号4位>-<2位序号>｜<标题>`（如 `F-AN0041-01｜境外收入占比>60%…`；**案号固定 4 位数字（案例层唯一案标识，容量 9999 案）、序号 2 位补零、编号与标题间用全角 `｜`**；禁空格、禁案代号字母入编号） |
| 规则要点 | 该条所依据的准则/法规/规则（如 CAS 14 主要责任人判断三要素）；只写规则本身，不写案情 |
| 本案实证 | 本案数据 + 页码（PAGE N），量化到金额/比例/期数；**无实证即无条目** |
| 可复用结论 | 对监管追问的应对要点（「回复须……禁止只写……」句式） |
| 对照锚点 / 旧条目关系标注（2026-09-03 新增；2026-09-05 格式同步实操版） | 三选一（编号+短语）：`[强化 F-050001 毛利率对比论证]` / `[扩展 F-140005 战略收缩可持续性核查]` / `[新增]`；多编号 `/` 连接、多命中 `；` 并列；依据 §S3.5 速览对照判定；未注入速览的轮次可标 `[待映射]` 由 S6a 补判 |

### 写作范式条目（每条 3 要素）
- **标题**：`### W-AN<案号4位>-<类><2位序号>｜<标题>`（如 `W-AN0041-A01｜"公司/发行人"双称谓功能分工`、`W-AN0041-F01｜"高毛利双锚对比"范式`）——**类位 = 单一白名单字母槽**：`A/B/C/D` = 句法族（A 称谓时点/B 限定严谨/C 结论句式/D 数据句式，写作角色 S5 词汇句法库）+ `F/L/I` = 业务域论证范式（财务/法律/行业专家产出，沿 C21 先例）；A-D 与 F-L-I 两组字母集合不相交，**同槽天然无碰撞**；E 位预留（预扩展族）。序号 2 位补零、`｜` 分隔
- 投行语言特征（遣词/口径/结构/论证四类之一）+ 原文实证（出处页码）+ 适用场景。
- 范式条目是**活库条目，S4 产出与 writer 落库同一编号**（案号在批登记表下发，专家直接按 `W-C{案号}-{类}{2位}` 编号）：S4 产出即落库形态，writer 只做内容归并/补族，**不再重编号**（消灭中间层编号漂移）；归并确需改类位时在蒸馏笔记登记映射

## §S5 写作范式提炼法（五步）

1. **精读要素**：精读招股书核心章节（业务与技术/财务分析/风险因素/募集资金运用）与问询回复原文，提炼投行语言要素：遣词造句（「发行人/公司/本公司」规范使用、「报告期内/截至本招股说明书签署日」时点表达）、披露口径、章节结构、论证逻辑、数据呈现方式
2. **建词汇句法库**（四类）：
   - 称谓与时点词：统一口径、全文一致
   - 限定与严谨词：避免绝对化、结论留余地
   - 结论句式：核查结论模板（「经核查，……真实、准确」「综上，……不构成重大违法违规」）
   - 数据句式：占比/复合增长率/调减/同比模板
3. **输出写作范式专题**：每条 = 投行语言特征 + 原文实证（出处页码）+ 适用场景
4. **反 AI 痕迹自检**：扫描「值得注意的是/综上所述」作衔接、「赋能/抓手/底层逻辑/颗粒度」黑话、排比三段式、过度连接词，逐一替换为投行表达
5. **增量合并**：新范式写入写作域（W 六位）供后续写作套用；**通用高频句式（跨 ≥5 案复用或族级通用）同步 `ibd-doc-write/references/writing-style.md`「高频句法库」**（skill 只存通用高频，案例级条目留 methods/，双轨不混）

### writer 落库产出规范（S5 · 2026-09-06 锁定）
- **单案范式文件顶层骨架固定七节**：`# 通用方法论：投行知识与写作范式（<公司> · 单案完整版）` → `## 〇、项目画像与关键数据快照` → `## 一、财务知识蒸馏（N 条 · <persona>并入）` → `## 二、法律知识蒸馏（…）` → `## 三、行业知识蒸馏（…）` → `## 四、「投行语言」写作范式专项（写作角色…，W-AN{案号4位} 族）` → `## 五、专家意见引用对照` → `## 六、质量自评报告`（禁止五节合并型骨架）

## §S5.5 模拟回复演练（五步）

①**选题**：从问询回复选 1 个核心问题（优先收入确认/毛利率/对赌清理/实控人认定）→ ②**独立撰写**：不先看原文，用词汇句法库写模拟回复框架（结构+句式完整，数据处标「待回查原文数据点」）→ ③**回查补齐**：读原文对应段落，补齐数据表/数字/条款原文/页码 → ④**对比**：我的稿 vs 真实回复，输出差距清单（结构/数据/措辞 ≥3 条，逐条说明差距性质）→ ⑤**沉淀**：可复用句式/结构写回词汇句法库或 W 系列；文件存 `{METHODS_ROOT}/cases/板块_简称_日期/`，关键差距摘要写入蒸馏笔记。
门禁：模拟回复标注「基于方法论撰写+原文数据回查」；差距清单 ≥3 条。

**实证教训（2026-08-15 模拟回复演练结论）**：框架层已掌握、**数据层未内化**——①每个结论配表格数据（数据密度）②引合同条款原文（证明力）③模拟调整后对比（毛利率质疑杀手锏）④主动回应追问点（跨期/废料影响量化）⑤风险揭示收尾。写文件必须主动回查原文补齐数据，不能只写框架。

## §S6 共通点判定标准

### 重合度分级（映射表判据）
| 重合度 | 判定 | 动作 |
|--------|------|------|
| 高 | 新条目与既有条目同一规则，新案提供更强实证 | 标「可作强化实证」，并入时追加实证 |
| 中/中高 | 规则相关但新案有特有升级（如新能源产业链特有矩阵） | 标「审慎性要点/特有升级」，并入时新增或扩展 |
| 低 | 无对应既有条目 | 新增条目 |

### 映射表模板（S6a 轻量映射，≤50 行）
```
| 新案条目 | 既有方法论对应条目 | 重合度 | 说明 |
```
实证（富士智能案）：`F-1 对账法收入确认 + 五迹象对照表 | 财务（29）（30）| 高 | 富士"签收 vs 对账"两栏五迹象表可作强化实证`。

### 双节奏触发
- **S6a 轻量映射（前置化 · 2026-09-03 起）**：每轮必做，产出 `共通点映射_板块_简称_日期.md`，不重写全文。**输入已含专家自带关系标注（§S3.5/§S4）**——lead 只做三件事：①校验标注与映射表一致性（防止专家误判重合度）②对 `[待映射]`/漏判条目补判 ③按 §S6 分级定稿并确定回写/新增清单。S6a 从「事后全量对比」降为「校验+补漏」，耗时下降、漏判率下降
- **S6b 全量蒸馏**：每 10 轮 或 累计新增 ≥60 条 或 用户指定时触发；重写最终版版本号（vN→vN+1），四章并行 writer 各自产出共通条目后主理人脚本拼接（`_merge_final_methodology.py`）；两次全量之间按域增量追加（不重排、不读全文）

### 反向更新旧条目（A-Mem 演化机制，2026-09-01 接入；2026-09-03 补门禁）
- **触发**：S6a 映射表产出「高/中高」重合条目 → S7 不回新增，**回写旧条目**（新知识重塑旧理解）
- **动作**：高重合=旧条目「本案实证」追加新案实证；中/中高=扩展「适用场景/特有升级」；低重合才新增条目
- **回写门禁（2026-09-03 新增）**：回写会改变域文件后续条目行号——**每轮回写完成后必须运行 `daily_distill.py refresh_index.py`**（与 S7 ④ 同一门禁，行号漂移会直接污染条目标题目录的定向读取）；回写条目须过护栏体检（check_methods_health.py 0 ERROR）
- **配套**：索引层跨域桥接速查表（gen_index.py 生成「三、跨域桥接速查表」）——查完本域条目按 Q 跨域跳转，双向支撑检索

### 冲突修订留痕（2026-09-03 新增 · 禁止静默覆盖）
- **触发**：新案实证与旧条目**规则本身冲突**（不是强化实证，而是推翻/修正结论——如监管口径变化、新案例证明旧判据不成立）
- **动作**：旧条目内追加「**修订记录**」行（`> 修订 YYYY-MM-DD（新案）：变更说明 + 依据页码`），**保留原表述不删除**；修订后规则以新版为准，旧表述标注「已修订」
- **升级路径**：涉及口径争议或跨域影响 → 登记「口径争议」由主理人统一裁定后落笔；重大规则变化（影响 ≥3 个旧条目）→ 提前触发 S6b 局部重写
- **反面清单**：禁止直接改写旧条目正文不留痕 / 禁止只在新案文件记冲突不回写旧条目 / 禁止以「新案更强实证」名义掩盖实质性规则变更（那走强化路径）

### 库进化度量（2026-09-03 新增 · 区分「进化」与「增长」）
- **落点**：每轮蒸馏笔记新增「**库进化统计**」小节，四项指标：①重合度分布（高/中高/低各占比）②回写旧条目数 ③新增条目数 ④冲突修订数
- **趋势判读**（S6b 复盘时汇总）：连续 2 个 S6b 周期「新增占比 >70%」→ 提示映射判据失效或选材行业跨度骤变，需复盘 §S6 分级判据；「回写占比持续 >60%」→ 库进入成熟收敛期，蒸馏重心应转向实证强化而非条目扩张
- **与护栏联动**：进化统计写入蒸馏笔记（KB 后端（默认 {METHODS_ROOT}/notes/）），S6b 汇总表同步 `methods/notes/`

## 多连轮批量优化要点（10 案批量模式）

1. **批量选材**：先 `选材校验脚本`（确认材料库招股书✓+反馈✓+文件数≥5）→ `批量准备脚本` 批量下载提取 → `--extract` 批量阅读包
2. **专家产出文件化为唯一准绳**：writer 直接读文件不回查消息流；任务书预填信息（板块/保荐/控制权）仅作参考，以专家产出文件为准（实证：上海超硅编号 11 个 vs 预填不符）
3. **并行 writer 编号集中分配**：主理人一次性分配各 writer W- 六位起始编号段，禁止自编、禁止从固定数自编（防重叠）
4. **口径争议登记**：专家与 writer 数据冲突登记统一裁定，按原文采用（实证：中图退役设备存货 6.26 亿 vs 原文 54,290.87/64,843.34/56,432.64 万元）
5. **网络波动应对**：批量 spawn 分 3 批（每批 ≤10）降低单点失败影响；api 502 DNS/aborted 属可恢复故障，失败即重试（prompt 自包含）；团队上下文丢失立即 TeamCreate 重建
6. **任务书 sponsor 标注「[以招股书为准]」**：快照 sponsor 常过期，专家发现冲突统一报「口径修正提示」
