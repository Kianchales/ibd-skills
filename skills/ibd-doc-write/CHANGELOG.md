## v0.4.1（2026-08-29）· 流水线顺序裁定

- **顺序裁定**：内容质量门禁在前、格式落地在后——草稿先过 `ibd-quality-gates`（数字五要素/反模式/G1-G5，md 即可跑）→ 再声明样式场景 → 交 `ibd-doc-review` 套样式 + 校验 →（可选）check_content 文档内自洽核对 → 交付
