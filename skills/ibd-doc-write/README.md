# ibd-doc-write（IBD 投行文档写作）

A 股 IPO 投行文档写作总入口：审核问询反馈回复、招股书章节、分析报告、尽调报告、备忘录、财务对比表。

本技能的核心承诺：**让 AI 写文件像投行人、不是 AI**——方法论强制引用（不引用即打回），表述套用投行语言规范、消除 AI 痕迹。

## 覆盖的文档

| 文档类型 | 入口 | 说明 |
|---------|------|------|
| 审核问询反馈回复 | 「写 XX 的反馈回复」「起草问询回复」 | 五步方法论调用链路 + G4 门禁 + 双段式结构 |
| 招股书章节 / 分析报告 / 尽调报告 / 备忘录 | 「写招股书章节」「写尽调报告」「写备忘录」 | 章节框架 + 结构规范 |
| 财务对比表 / IPO 核对表（Excel） | 「做 XX 对比表」 | 表格结构 |

## 写作流程（三段式）

1. **文档类型路由**：先识别类型，再走对应 `references/`（response-chain 反馈回复专用 / doc-structures 报告类）
2. **方法论强制引用**（反馈回复）：拆问询问题 → 查映射索引（28 问询域）→ 行号级定向读方法论 → 套投行语言句法库 → 交付前 G4 引用清单自检
3. **格式落地串联**：本 skill 只产出**内容草稿**，样式与格式核对交给下游（见依赖）

## 与生态内其他技能的分工

```
doc-write 写草稿 → quality-gates 内容质量门（数字五要素/反模式/G1-G5 + 数值自洽）→ doc-review 套样式 + 格式核对 → 交付
```

- **内容质量**（数字可溯源/判断有依据/无绝对化表述）→ `ibd-quality-gates`
- **格式落地**（样式/序号/表格规范）→ `ibd-doc-review`
- 顺序规则：内容质量门禁在前、格式落地在后——草稿阶段过门，改稿成本最低

## 安装与依赖

本技能为「引用外部依赖」发布：以下依赖**不随本包携带**，安装后须自行补齐：

| 依赖 | 版本下限 | 用途 | 获取 |
|------|---------|------|------|
| `ibd-quality-gates` | ≥ 0.7.0 | 内容质量门禁（G1-G5 + 数值自洽） | GitHub 集合仓库 `Kianchales/ibd-skills`（`skills/` 子目录），与获取本技能同一来源 |
| `ibd-doc-review` | ≥ 0.15.0 | 样式落地 + text/table 格式校验 | 同上 |

缺 gates/review 时本技能仍可写作，但产出为未过门的草稿；补装后即可完整运行。
