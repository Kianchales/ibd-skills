# 文档类型与结构规范

> 适用：🔵 招股书章节 / 分析报告 / 尽调报告 / 备忘录 / 财务对比表 / IPO 核对表
> 归属：ibd-doc-write（全文档写作）
> 使用：动笔前先读本文档对应文档类型章节，再按模板触发映射（templates-map.md）加载模板与知识库范例。

## 招股书分析报告（Word）

```
一、项目概况
  - 发行人基本信息、板块、行业分类、审核状态
二、财务分析（综合财务分析意见）
  - 财务数据概览、收入确认、毛利率、应收账款、关联交易等
  - 风险提示与关注事项
三、法律分析（综合法律分析意见）
  - 主体资格、股权结构、公司治理、同业竞争、关联交易、诉讼等
  - 合规判断与风险提示
四、行业分析（综合行业分析意见）
  - 行业定位、市场规模、竞争格局、核心技术、成长性
  - 行业风险与机遇
五、综合评估
  - 优势汇总、风险汇总、审核关注点预判
六、附件
  - 数据表格、可比公司列表
```

## 尽职调查报告（Word）

```
一、尽职调查概述
  - 调查范围、方法、时间
二、公司基本情况
三、业务与技术
四、财务与会计
五、法律与合规
六、风险因素
七、调查结论与建议
```
