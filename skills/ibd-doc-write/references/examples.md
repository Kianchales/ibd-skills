# 使用示例（examples.md）

> 最小复现示例：对话触发 → 执行链路 → 交付物结构。本包为知识/流程型 skill，示例展示「用户一句话 → AI 该走的路」。
> 反馈回复完整五步链路见 [response-chain.md](response-chain.md)；结构规范见 [doc-structures.md](doc-structures.md)。

## 示例 1：审核问询反馈回复（核心场景）

**用户触发**：「写 XX 公司第一轮审核问询反馈回复」

**AI 执行链路（节选）**：
1. 路由 → 反馈回复类 → 读 `response-chain.md` 五步链路
2. ⓪ 方法论版本感知 → ① 拆问询问题（如：毛利率下滑原因 / 应收账款周转 / 对赌清理）→ ② 查方法论索引（28 问询域 → Q 编号）→ ③ 行号级定向读方法论条目
3. ④ 套投行语言（WL 族句式）→ 草稿完成
4. ⑤ 内容门禁：`ibd-quality-gates` G1-G4 + 自评 + `check_data.py` 数值自洽 → 对照表标注「依据方法论点 vN」

**交付物结构**（按 response-chain 双段式）：

```
XX公司_首轮问询反馈回复.md
├── 问题 1. 关于毛利率变动
│   ├── 回复正文（首句直接回答问题 → 数据支撑 → 原因分析）
│   └── 引用标注（F-010001 等方法论条目）
├── 问题 2. 关于……
└── G4 引用清单（问询问题 → 方法论条目 → 使用位置）
```

## 示例 2：招股书章节 / 报告 / 备忘录

**用户触发**：「写尽调报告的客户与供应商章节」

**执行链路**：路由 → `doc-structures.md` 对应章节框架 → 套投行语言规范 → 内容门禁 → 交 `ibd-doc-review` 套样式。

## 依赖提醒

本包产出**内容草稿**；样式落地与格式核对归 `ibd-doc-review`（≥0.15.0），内容质量门禁归 `ibd-quality-gates`（≥0.7.0）——两依赖不随包携带，见 SKILL.md「依赖与工具」断链自助。
