# 方法论库消费指引（METHODS Guide · 消费侧精简版）

> 适用：🟢 通用——doc-write 所有使用者，**特别是没有现成方法论库的新使用者**
> 归属：ibd-doc-write（**消费侧**：库怎么被写作引用 + 无库降级）
> **完整规范**（目录/条目结构/索引机制/规模化拆分/工具链）→ 见 `ibd-methods-ops` 的 `references/methods-guide.md`（规范单一事实源；可选安装，无它时按本文件精简版自建即可）

## 方法论库是什么

- 一个「按问题域索引的知识库」：写作时按问询问题类型，定向查「这类问题以前怎么答得好」
- doc-write 的 G4 引用自检要求引用它——每个结论都能溯源到方法论条目（防编造、防 AI 味）
- **它不属于 skill 本身**：skill 只存通用高频句式（writing-style.md）；方法论库是你的知识积累，天然绑定你的业务领域

## 库接入（开放后端 · 由 ibd-methods-ops 引导配置）

方法论库**不锁定产品**——本地目录 / Obsidian / 乐享 / ima / 任意 MCP 知识库 / 云文档等皆可接入（示例非穷举，用户自行接入）。接入与配置由 `ibd-methods-ops` 的「库配置」四问引导完成并记录（配置文件 `library.config.json`）。本 skill 引用库时按配置的**能力档位**读取：A 档（文件型）走文件路径，B 档（检索型）走连接器搜索。完整对照见 ops 的 methods-guide §二。

## 最小起步结构（3 文件）
> 适用 A 档（文件型）；B 档（检索型）无需本地文件结构（直接在其空间内沉淀）。

```
{METHODS_ROOT}/                ← 方法论正文根（路径可配置；脚本 --methods-root 传其上一层＝库根/工作区根）
├── 通用方法论_最终版.md        ← 稳定入口：全部条目
├── 方法论调用索引.md           ← 核心入口：问题域速查表（Q1-QN）→ 条目编号映射（兼编号唯一性凭证）
└── 方法论_条目标题目录.md      ← 标题 + 行号目录（行号定位精读用）
```

> 早期版本含 `编号登记表.md`——该资产已于 **2026-09-01 退役**（迁 `archive/`）；编号唯一性与防重改由**调用索引全量映射 ＋ 条目标题目录**保障。

> 库变大（单文件读取成本高 / 超过 ~300KB）后，可按 ibd-methods-ops 的完整规范拆分域文件（入口薄壳 + 各域文件），并用其随包脚本自动生成索引。

## 条目结构规范（新条目必须遵守 · 与完整规范同源）

1. **标题**：编号 + 一句话可复用结论（编号形如 `F-010001` / `L-010001` / `I-010001` / `S-010001`（体例） / `WL-010001`（回复语言） / `PL-`（招股书语言），追加 = 目标族内 max+1）
2. **方法论要点**：规则/句式/论证模式（可直接套用，允许 `{占位符}`）
3. **本案实证**：出现过的案名清单（跨案标注的依据）
4. **适用场景**：什么类型的问题用（对应 Q 域）

## 建立方式（边用边长 · 与写作闭环）

1. **建库**：创建 `{METHODS_ROOT}` + 上述 3 个基础文件（空索引模板见文末）
2. **直接开始写作**：无库阶段跳过 ②③（无条目可查），凭 `writing-style.md` 高频句法库 + 通用写作规范完成
3. **每次写作后沉淀（关键回环）**：复盘「哪条可复用结论/句式值得记下来」→ 分配编号 → 按四段结构追加条目 → **刷新索引**（调用索引 + 条目标题目录 + 路由入口一次同步；装了 `ibd-methods-ops` 时跑其 `refresh_index.py`）
4. **高频判定**：通用高频（≥5 案复用或族级通用）→ 同步进本 skill 的 `writing-style.md` 高频句法库
5. **积累 10-20 条后**：写作体验明显提升；建议固定节奏（如每月）复核补齐

> **方法论库不是建完即用的静态文件**——它必须随每次写作/每轮蒸馏持续更新，否则「缺条目」会越来越频繁。有 `ibd-methods-ops` 时可用其蒸馏流程批量沉淀 + 脚本维护。

## 库缺失/缺条目时的降级（G4 适配 · 保持可写）

> **核心原则：方法论库的任何缺口都不阻断写作**——提示使用者 → 降级引用 → 继续完成，写完后沉淀补库。

**场景一 · 无库（新使用者尚无 METHODS_ROOT）**
- 五步链路中 ②③ 可跳过（无库可查）；① 拆问询 / ④ 套句式 / ⑤ G4 照常
- 凭 `writing-style.md` 高频句法库 + 通用写作规范直接完成写作

**场景二 · 有库但该问题缺条目（常见于库还在积累期）**
- 查索引未命中 → **先向使用者明确提示**：「该问题（如：收入确认）在方法论库暂无对应条目，本次以降级方式完成，写作后将沉淀补库」
- 继续降级写作：引用 `writing-style.md` 高频句法库对应句式 + 通用写作规范

**两种场景共同的 G4 规则**
- G4 对照表允许「本库暂无对应条目」声明，但必须附：① 引用了哪些通用高频句式（writing-style.md 条目）② 该问题标记「待沉淀」加入待积累清单
- **不允许**：不引用任何来源直接写——防编造铁律不变，只是把「引用对象」从方法论库临时换成 skill 高频句法库
- **写完后**：按上文回环沉淀，把本次「待沉淀」问题补成正式条目

## 外部引用路径清单（由 SKILL.md「资源索引 · 外部引用路径」下沉）

> **版本感知（G5 · 方法论库是活资产）**：方法论库随每轮蒸馏持续升版（`--refresh-index` 自动同步）——**写作引用前先读 `{METHODS_ROOT}/通用方法论_最终版.md` 头部版本指引行确认当前 vN**，引用清单/交付说明标注「依据方法论点 vN」；蒸馏刚升版后条目编号与行号已刷新，以新索引为准，勿引用旧版编号。

> **接入与自建不在此重复**（单一事实源）：「库接入」见本文件同名节、「边用边长」见「建立方式」节、「无库怎么走」见「库缺失/缺条目时的降级」节；**完整规范**（域拆分／索引机制／批量沉淀与维护工具链）见可选依赖 `ibd-methods-ops` 的 `references/methods-guide.md`。**本节只列路径清单。**

- **方法论调用索引**（核心入口）：`{METHODS_ROOT}/方法论调用索引.md`（问题域 Q1-QN → 条目编号映射；示例：`~/methods/` 或任意绝对路径）
- **最终方法论（稳定入口）**：`{METHODS_ROOT}/通用方法论_最终版.md`（升版由 `--refresh-index` 自动同步）
- **条目标题目录**：`{METHODS_ROOT}/方法论_条目标题目录.md`（含行号列，支持行号定位）
- **行业方法论**：`{METHODS_ROOT}/行业方法论_{类名}.md`（**扁平文件**，按类名，无「合并版」子目录）；单一公司行业研究在 `{METHODS_ROOT}/行业方法论_单份细分版/`
- **单案方法论**：`{METHODS_ROOT}/单案/通用方法论_投行知识与写作范式_{规范案名}.md`（2026-09-16 起归拢至 `单案/`；**案名一律用证券简称**，案号对照见工作区根 `state/单案索引对照表.md`）
- **语言专项（W / P 系列）**：回复句式 `{METHODS_ROOT}/投行语言专项_W系列.md`；招股书语言范式 `PL-`（正文在 `{METHODS_ROOT}/分卷/投行语言专项_P系列_卷N.md`，按索引「附：P 系列」定卷后读）
- **投行语言词汇句法库**：`references/writing-style.md` + 方法论 W- 系列主题族（六位编号）
- **同类模板/案例**：KB_BACKEND（公司内部 Wiki/云文档/本地目录任选，检索同类案例）
