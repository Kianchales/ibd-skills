# 方法论库建立与维护指引（METHODS Guide）

> 适用：🟢 通用——doc-write 所有使用者，**特别是没有现成方法论库的新使用者**
> 归属：ibd-doc-write
> 目的：让任何人在 doc-write 的协作下，**从零建立并持续积累自己的方法论库（METHODS_ROOT）**

## 方法论库是什么

- 一个「按问题域索引的知识库」：写作时按问询问题类型，定向查「这类问题以前怎么答得好」
- doc-write 的 G4 引用自检要求引用它——每个结论都能溯源到方法论条目（防编造、防 AI 味）
- **它不属于 skill 本身**：skill 只存通用高频句式（writing-style.md）；方法论库是你的私人知识积累，天然绑定你的业务领域

## 目录结构（METHODS_ROOT）

```
{METHODS_ROOT}/   ← 方法论库根目录（路径可配置，见 SKILL.md「引用资源路径」）
├── 方法论调用索引.md              ← 核心入口：问题域速查表（Q1-QN）→ 条目编号映射
├── 通用方法论_最终版.md           ← 稳定入口：全部条目全文（W/F/L/I 四域分章）
├── 方法论_条目标题目录.md         ← 标题 + 行号目录（支持行号定位精读，不全文翻找）
├── 编号登记表.md                  ← 编号 → 条目映射（四域登记，防重防丢）
├── 行业方法论_{类名}.md           ← 行业合并版（可选，按证监会行业分类归组）
├── 通用方法论_投行知识与写作范式_{案名}.md  ← 单案文件（可选）
└── archive/                       ← 历史归档（可选，久远条目移入并保留索引行）
```

## 条目结构规范（新条目必须遵守）

- **编号**（v37 体系）：主库四域 `域-族号2位-族内4位`——`W-010001`（写作 12 族）/ `F-010001`（财务 18 族）/ `L-010001`（法律 19 族）/ `I-010001`（行业 15 族）；投行语言 `WL-xx-xxxx`（20 族）。**蒸馏追加 = 目标族内 max+1**（族号查登记表或现有文件族标题）；自己集中分配（防重叠），永不回收；单案范式文件用 `域-C{NN}-序号`（C=案号，见单案索引对照表）
- **四段结构**（每条固定）：
  1. **标题**：含编号 + 一句话可复用结论（如「W-000001 收入确认三层分层披露」）
  2. **方法论要点**：规则/句式/论证模式（可直接套用的形态，允许 `{占位符}`）
  3. **本案实证**：出现过的案名清单——这是跨案标注的依据
  4. **适用场景**：什么类型的问题用（对应 Q 域）
- **跨案标记**：实证去重 ≥5 案 → 标题标 `【N案共通】` → 这是「沉淀进 skill 高频句法库」的候选（见写作→沉淀回环）

## 如何建立你的方法论库（两种方式）

### 方式 A：边用边长（推荐起步 · 与 doc-write 协作闭环）

1. **建库**：创建 METHODS_ROOT 目录 + 按上文结构建 4 个基础文件（空索引模板见文末）
2. **直接开始写作**：走五步链路时，无库阶段跳过 ②③（无条目可查），凭 `writing-style.md` 高频句法库 + 通用写作规范完成
3. **每次写作后沉淀（关键回环 · 持续更新铁律）**：
   - **方法论库不是建完即用的静态文件——它必须随每次写作/每轮蒸馏持续更新**，否则「缺条目」会越来越频繁，降级越来越常见
   - 复盘：这篇（如收入确认/毛利率质疑）的答法里，哪条「可复用结论/句式」值得记下来？
   - 分配编号 → 在 `通用方法论_最终版.md` 对应域章节末尾追加条目（四段结构）
   - 同步登记：`方法论调用索引.md`（Q 域 → 新条目）+ `方法论_条目标题目录.md`（标题+行号）+ `编号登记表.md`
   - **高频判定**：该条是通用高频（≥5 案复用或族级通用）→ 同步进本 skill 的 `writing-style.md` 高频句法库
4. **积累 10-20 条后**：写作体验明显提升——查得到自己的经验，G4 引用有据可依
5. **长期维护**：建议按固定节奏（如每月）复核一次索引与条目的完整度，把写作中标记「待沉淀」的问题补上，保持库与业务同步增长

### 方式 B：蒸馏式积累（完整版 · 结构化产出）

- 适合批量复盘招股书/问询回复：选材 → 多维专家并行精读（或自行）→ 综合成文 → 共通点蒸馏 → 沉淀入库
- 产出结构化程度高（条目+跨案标注+行业归组），但需要多角色协作，成本高
- 完整流程（可选参考）：有配套「方法论生产/维护」流程或工具时可编排蒸馏；无则按上方方式 A/B 自建条目入库（自包含，不阻塞）

## 方法论库缺失/缺条目时的降级（G4 适配 · 保持可写）

> **核心原则：方法论库的任何缺口都不阻断写作**——提示使用者 → 降级引用 → 继续完成，写完后沉淀补库。

**场景一 · 无库（新使用者尚无 METHODS_ROOT）**
- 五步链路中 ②③ 可跳过（无库可查）；① 拆问询 / ④ 套句式 / ⑤ G4 照常
- 凭 `writing-style.md` 高频句法库 + 通用写作规范直接完成写作

**场景二 · 有库但该问题缺条目（常见于库还在积累期）**
- 查索引未命中 → **先向使用者明确提示**：「该问题（如：收入确认）在方法论库暂无对应条目，本次以降级方式完成，写作后将沉淀补库」
- 继续降级写作：引用 `writing-style.md` 高频句法库对应句式 + 通用写作规范

**两种场景共同的 G4 规则**
- G4 对照表允许「本库暂无对应条目」声明，但必须附：① 引用了哪些通用高频句式（writing-style.md 条目）② 该问题标记「待沉淀」加入你的待积累清单
- **不允许**：不引用任何来源直接写——防编造铁律不变，只是把「引用对象」从方法论库临时换成 skill 高频句法库
- **写完后**：按方式 A 回环沉淀，把本次「待沉淀」问题补成正式条目——这正是方法论库持续更新的来源

```markdown

## 问题域速查表

| Q 编号 | 问题域 | 条目编号 |
|--------|--------|---------|
| Q1 | 收入确认 | （待沉淀）|
| Q2 | 毛利率 | （待沉淀）|
| Q3 | 对赌清理 | （待沉淀）|
| ... | ... | ... |

## 全量映射表
> 新增条目后在此登记：Q 域 → 条目编号 → 标题
```

## 与本 skill 其他文件的关系

| 文件 | 角色 | 与新方法论库的关系 |
|------|------|-------------------|
| `references/writing-style.md` | skill 自带高频句法库（通用高频，已沉淀） | 你的方法论库高频条目 → 回流到这里（跨 ≥5 案或族级） |
| `references/response-chain.md` | 五步链路（②③ 查 METHODS_ROOT） | 链路不变，METHODS_ROOT 换成你的库 |
| `references/doc-structures.md` / `templates-map.md` / `context-rules.md` | 结构/模板/上下文 | 与库无关，照常用 |
