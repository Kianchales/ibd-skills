# 反馈回复写作 · 五步强制调用链路

> 适用：🟠 反馈回复专属（仅审核问询反馈回复类任务）
> 归属：ibd-doc-write
> G4 引用自检依赖，缺一步即不合格。

## 五步链路

> ②③ 依赖**方法论库（METHODS_ROOT）**——路径见 SKILL.md「引用资源路径」，可配置；**新使用者无库时跳过②③走降级**；**有库但某问题未命中时，向使用者明确提示后继续降级**（①④⑤照常，G4 允许「暂无对应条目」声明，详见 `methods-guide.md`「方法论库缺失/缺条目时的降级」）。**方法论库需持续更新**——每次写作后按 `methods-guide.md` 方式 A 沉淀，保持缺条目频次下降。

```
拿到问询函
  → ⓪ 方法论版本感知（凡引用方法论必做）：读 {METHODS_ROOT}/通用方法论_最终版.md 头部版本指引行 → 确认当前 vN（蒸馏每轮升版由 --refresh-index 自动同步）——本次引用一律以该 vN 条目为准，⑤ 对照表标注「依据方法论点 vN」，防蒸馏刚升版时误引旧版编号/行号
  → ① 拆问询问题：把每个问询问题拆解为方法论主题（收入确认/毛利率/对赌清理/实控人/客户集中/募投产能消化等）
  → ② 查映射索引（**检索链路可选依赖**：有配套「方法论检索」工具时调用其标准链路；无则按本文件内嵌流程——打开 {METHODS_ROOT}/方法论调用索引.md → 顶部「问题域速查表」找到 Q 编号 → 去全量映射表查该 Q 下所有条目）：**未命中 → 提示使用者「该问题暂无对应条目」→ 标记「待沉淀」→ 跳③ 继续 ④**
  → ③ 定向读方法论（**行号定位**：条目标题目录含「行号」列，用 Read offset/limit 精准读条目正文，不全文翻找；检索细节按 ② 内嵌流程即可，不依赖外部 skill）：
        a. 主库对应条目：{METHODS_ROOT}/通用方法论_{财务/法律/行业/体例}域.md（族号体系 F-/L-/I-/S-，形如 F-010001；行号见 {METHODS_ROOT}/方法论_条目标题目录.md）
        b. 行业方法论对应类：{METHODS_ROOT}/30_行业版/行业方法论_{类名}.md（15 类；按该案证监会行业分类归组）；单一公司行业研究在**该案单案文件对应章**（原 `30_行业版/单份细分版/` 载体 2026-09-23 停用撤除）
        c. 单案范式：{METHODS_ROOT}/单案/通用方法论_投行知识与写作范式_<规范案名>.md（域-AN案号4位-序号，形如 F-AN0015-01；**案名一律用证券简称**、案号见 `state/单案索引对照表.md`〔工作区根〕）；无单案文件的案（22 案）经索引对照表路由到 `cases_md/`
        d. 语言专项：招股书段落范式走「附：P 系列」→ {METHODS_ROOT}/分卷/投行语言专项_招股书PL系列_卷N.md（先定卷、再按行号读）；W 系列句式在 {METHODS_ROOT}/投行语言专项_回复WL系列.md
  → ④ 套回复语言域句式：回复表述套用 WL- 句式（族号体系，形如 WL-040002）（双段式结构、剔除还原句式、结论句式、限定词），避免 AI 痕迹
  → ⑤ G4 引用清单自检：交付前生成「问询问题类型→方法论条目编号（v37：主库 域-族号2位-族内4位 F-010001 / 单案 域-AN案号4位-序号 F-AN0015-01 / 回复语言 WL-xx-xxxx）→使用位置」对照表，随质量自评报告附上
```

## 投行语言专项句式（回复专用）

- **双段式结构**：【发行人说明与披露】逐项编号四级标题 + 【中介机构核查及说明】（核查程序逐项定义抽样标准 + 核查结论）；监管问题黑体、回复宋体本身就是合规展示。
- **业绩波动"同口径还原"**：先实际变动 → 归因 → 剔除还原 → 区间预计，附"未经审计、不构成盈利预测或业绩承诺"。
- **处罚/合规结论句模板**："鉴于(1)(2)(3)(4)…综上不构成重大违法违规"。
- **条款锚定式论证**："规则—事实—结论"三段式，先引监管规则原文再逐项论证。

## G4 引用自检（使用者/负责人核对）

- 交付必须附「问询问题类型→方法论条目编号（v37：F-010001 / F-AN0015-01 / WL-xx-xxxx）→使用位置」对照表
- **未引用任何方法论（对照表为空）即打回补引**；引用条目须实际用于正文论证，不得空挂编号
- 交付物末尾附质量自评报告（含 G1-G4 状态 + AP-W 命中/修复清单）

## 语言范式取用（第 ④ 步详规 · 由 SKILL.md §2 下沉）

> 与 ②③ **同源检索 · 必做**：沿用 ② 已定位的 Q 域，从索引取该 Q 下的语言条目 → 行号定位定向读 → 套用句式（避免 AI 痕迹）。

- **语言范式与业务方法论同一次检索取得**，勿凭记忆、也勿仅凭 skill 内静态句法库写作
- `references/writing-style.md` 仅作**兜底**（无库/无检索时降级用），不作主力——它只覆盖库内 W/P 系列数百条中的极小部分
- **按文档类型分流（2026-09-10 新增）**：写**回复**取 W 系列（`WL-xxxxxx`）；写**招股书**取 P 系列（`PL-xxxxxx`）——索引附表已标「语用／方法」两层，写招股书时**排除回复语用条目**，对「方法通用」条目标注「方法可借、语用须转」；**P 系列尚在补做中（当前库内招股书语用仅 3 条）**，此阶段以 `doc-structures.md` 结构规范 ＋ 通用条目为主，**勿套用回复句式**
- **跨案参考（同行业价值最高）**：写具体项目时先查该案或同类案的**单案写作范式** `{METHODS_ROOT}/单案/通用方法论_投行知识与写作范式_{案名}.md`（含该案完整写作范式 + W-AN 族条目；2026-09-16 起单案归拢至 `单案/` 子目录）
- ⑤ 步的 G4 对照表须**把 ④ 步取用的语言条目一并列入**（证明句式取自库、非臆造）

## 第 ② 步补充 · 跨域桥接（由 SKILL.md §2 下沉）

- 打开 `{METHODS_ROOT}/方法论调用索引.md` → 顶部「**28 个问询问题域**速查表」找到 Q 编号 → 去全量映射表查该 Q 下所有条目
- **跨域补充**：查「三、跨域桥接速查表」看各域代表条目（财务/法律/行业/写作桥接，A-Mem 语义链接）

## G4 引用自检 · 降级两场景与库更新（由 SKILL.md「G4 引用自检」下沉）

> **完整规则单一事实源 → 本包 `methods-guide.md`「库缺失/缺条目时的降级」**（不在此复制）。本步骤只记**写作侧一句话判据**：
> **无库时 ②③ 跳过、④ 降级用 `writing-style.md` 兜底**（＝**降级档位**：语言范式覆盖率大幅下降，「能写、但不地道」），有库后回到标准链路；**G4 对照表可声明「本库暂无对应条目」，但不得零引用直接写**（须附所引句式 ＋「待沉淀」标记）。
>
> 口径更正：本节原写「②③④ 跳过」，与 `methods-guide.md`「④ 套句式照常（降级到 writing-style）」**矛盾** ⇒ 以「②③ 跳过、**④ 降级不跳过**」为准（与 `response-chain.md`「语言范式取用」节一致）。
