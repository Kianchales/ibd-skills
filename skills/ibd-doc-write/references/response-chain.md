# 反馈回复写作 · 五步强制调用链路

> 适用：🟠 反馈回复专属（仅审核问询反馈回复类任务）
> 归属：ibd-doc-write
> G4 引用自检依赖，缺一步即不合格。

## 五步链路

> ②③ 依赖**方法论库（METHODS_ROOT）**——路径见 SKILL.md「引用资源路径」，可配置；**新使用者无库时跳过②③走降级**；**有库但某问题未命中时，向使用者明确提示后继续降级**（①④⑤照常，G4 允许「暂无对应条目」声明，详见 `methods-guide.md`「方法论库缺失/缺条目时的降级」）。**方法论库需持续更新**——每次写作后按 `methods-guide.md` 方式 A 沉淀，保持缺条目频次下降。

```
拿到问询函
  → ⓪ 方法论版本感知（凡引用方法论必做）：读 {METHODS_ROOT}/通用方法论_最终版.md 头部版本指引行 → 确认当前 vN（蒸馏每轮升版由 --refresh-index 自动同步）——本次引用一律以该 vN 条目为准，⑤ 对照表标注「依据方法论点 vN」，防蒸馏刚升版时误引旧版编号/行号
  → ① 拆问询问题：把每个问询问题拆解为方法论主题（收入确认/毛利率/对赌清理/实控人/客户集中/募投产能消化等）
  → ② 查映射索引（**检索链路可选依赖**：有配套「方法论检索」工具时调用其标准链路；无则按本文件内嵌流程——打开 {METHODS_ROOT}/方法论调用索引.md → 顶部「问题域速查表」找到 Q 编号 → 去全量映射表查该 Q 下所有条目）：**未命中 → 提示使用者「该问题暂无对应条目」→ 标记「待沉淀」→ 跳③ 继续 ④**
  → ③ 定向读方法论（**行号定位**：条目标题目录含「行号」列，用 Read offset/limit 精准读条目正文，不全文翻找；检索细节按 ② 内嵌流程即可，不依赖外部 skill）：
        a. 主库对应条目：{METHODS_ROOT}/通用方法论_{财务/法律/行业/写作}域.md（族号体系 F-010001；行号见 {METHODS_ROOT}/方法论_条目标题目录.md）
        b. 行业合并版对应类：{METHODS_ROOT}/行业方法论/合并版/（按该案证监会行业分类归组）
        c. 单案范式：{METHODS_ROOT}/通用方法论_投行知识与写作范式_<公司>.md（域-C{NN}-序号，案号见单案索引对照表）；无文件案经索引路由 cases/
  → ④ 套投行语言词汇句法库：回复表述套用 WL-xx-xxxx 句式（投行语言专项，族号体系）（双段式结构、剔除还原句式、结论句式、限定词），避免 AI 痕迹
  → ⑤ G4 引用清单自检：交付前生成「问询问题类型→方法论条目编号（v37：主库 域-族号2位-族内4位 F-010001 / 单案 域-C{NN}-序号 F-C15-01 / 投行语言 WL-xx-xxxx）→使用位置」对照表，随质量自评报告附上
```

## 投行语言专项句式（回复专用）

- **双段式结构**：【发行人说明与披露】逐项编号四级标题 + 【中介机构核查及说明】（核查程序逐项定义抽样标准 + 核查结论）；监管问题黑体、回复宋体本身就是合规展示。
- **业绩波动"同口径还原"**：先实际变动 → 归因 → 剔除还原 → 区间预计，附"未经审计、不构成盈利预测或业绩承诺"。
- **处罚/合规结论句模板**："鉴于(1)(2)(3)(4)…综上不构成重大违法违规"。
- **条款锚定式论证**："规则—事实—结论"三段式，先引监管规则原文再逐项论证。

## G4 引用自检（使用者/负责人核对）

- 交付必须附「问询问题类型→方法论条目编号（v37：F-010001 / F-C15-01 / WL-xx-xxxx）→使用位置」对照表
- **未引用任何方法论（对照表为空）即打回补引**；引用条目须实际用于正文论证，不得空挂编号
- 交付物末尾附质量自评报告（含 G1-G4 状态 + AP-W 命中/修复清单）
