# 投行语言写作规范

> 适用：🟢 通用（反馈回复 + 招股书/报告 + 备忘录，所有文档类型）
> 归属：ibd-doc-write
> 核心目标：让 AI 写的文件像投行专业人士写的，而不是 AI 写的。
> 编号体系：方法论条目编号为六位（W-000001 等），详见 `{METHODS_ROOT}/方法论调用索引.md`。

## 投行语言词汇句法库（写作时强制套用）

- **称谓与时点词**：发行人/本公司/报告期各期/报告期末/截至本招股说明书签署日/截至 YYYY-MM-DD——统一口径、全文一致
- **限定与严谨词**：主要系/主要由于/一般认为/在……情况下/通常情况下/具有合理性/不存在……的情形/经核查/综上——避免绝对化、结论留有余地
- **结论句式**：经核查，……真实、准确 / 综上，……不构成重大违法违规 / 该测算具备合理性和可参考性 / 不存在明显超前建设的情况
- **数据句式**：占比为 X.XX% / 复合增长率为 X% / 由 X 调减至 Y / 较上年同期增长/下降 X%
- **反 AI 痕迹**：黑名单词（值得注意的是/综上所述作衔接/赋能/抓手/底层逻辑/颗粒度）出现即替换；禁排比三段式、过度连接词

## 高频句法库（≥5 案共通或族级通用）

> 来源：`{METHODS_ROOT}/通用方法论_最终版.md`（十轮共通写作范式 + 第五章 W- 系列四族归组）。完整条目与案例实证见方法论，此处为写作时直接套用的高频句式；引用编号用于 G4 对照。

### 一、回复结构类（十轮共通 · ≥5 案验证）

- **五段式骨架（W-000046 区域 · 十轮共通）**：问询回复通用骨架 = ①问题拆解 → ②量化表格 → ③逐因素归因 → ④核查程序 → ⑤明确结论。核查程序逐项编号穷举（"1、2、3、…9"，每项"动作＋对象＋目的"），结论句与问题子项一一对应编号（"经核查……认为：（1）…（2）…"）。毛利率/业绩类以"说明"为主、核查可简化并入末尾；收入真实性/法律类保留完整四段式。
- **双段式结构**：【发行人说明与披露】逐项编号四级标题 + 【中介机构核查及说明】（核查程序逐项定义抽样标准 + 核查结论）；监管问题黑体、回复宋体本身就是合规展示。
- **测算"三件套"（十轮共通）**：任何测算写作 = ①公式显式化（等号形式，"年降金额=（上期销售价格-本期销售价格）×本期销量"）②参数来源与假设（年工作日/售后期/供货份额/汇率基准日）③实例演算（具体产品代入，可复核），末句"与同行业可比公司具有一致性/测算数据准确"。敏感性双向测算（±1%/3%/5%）防单边假设质疑。
- **业绩"同口径还原＋期后验证＋风险提示"三重披露（十轮共通）**：①现状量化 → 同口径剔除还原（汇兑/政府补助/资产处置等非经常性因素）②期后数据验证（注明审阅报告文号）③风险提示（量化，附"未经会计师审计或审阅、不构成盈利预测或业绩承诺"声明）。"剔除还原"亦用于毛利率/客户层面异常数据解释（"如剔除××影响，毛利率为 W%"）。
- **毛利率问询"归因矩阵＋贡献率表"（十轮共通）**：①归因维度逐层编号（产品结构→客户车型→定价机制→单位价差）②每维度数据（收入占比/单价/成本变动）＋"影响 X 个百分点"③贡献矩阵（=毛利率×收入占比）④原材料敏感性表（±5%/10%/20%）⑤"先排除后聚焦"⑥结论"五要素收束"。可比公司对比另加"先定可比标准再逐层拆解"。
- **存货跌价"分类型逐类披露＋四件套"（十轮共通）**：①分类型逐类披露计提逻辑与比例 ②高价值非标存货"为何计提/计提比例/参考依据"三类并列 ③"订单覆盖率/库龄/呆滞/可比对比"四件套 ④低周转先归因业务结构再"剔除相关业务后"还原。
- **市占率/市场规模"口径显式化＋公式＋波动风险"（十轮共通）**："根据××（机构全称）统计数据测算，公司 2025 年××全球市场占有率约 X%"；公式等号显式；主动披露估算波动风险；双口径并列时逐一注明口径定义；预测数据标注预测年份与 CAGR。

### 二、族 A 遣词类（称谓/时点/限定词 · 通用）

- **称谓切换**："发行人"首次出现后全文以"公司"为主、监管要求处用"发行人"；三年数据一律按旧→新顺序（2023/2024/2025），全文不得混用。
- **限定词**："主要系/主要受"保留非全部归因空间；排除句用双否定式"不存在……的情形/未发生……的情形"；数据源声明"并非为公司本次发行上市专门定制的第三方报告"堵质疑。
- **期后限定**："未经审计或审阅、不构成盈利预测或业绩承诺"强制附加于期后数据/预测。

### 三、族 B 口径类（收入确认/产能/市占率口径 · 通用）

- **收入确认"三层分层"**："报告期内，公司以{签收/验收/报关}为收入确认时点的收入金额占比分别为 A、B、C 万元，占比分别为 X%、Y%、Z%，为公司主要收入确认方式"——三种方式单列金额+占比，先文字总述再表格分列。
- **"先款后货"因果链**："以{先款后货}为主的结算模式使得公司在实现销售的同时即收回货款，期末应收账款余额极小，是公司{应收账款周转率}远高于同行业可比公司的直接原因"。
- **分批次交付特例**："鉴于{分批次交付的产品}尚不能构成{合同约定的完整商品}，{客户}无法直接使用并从中获取经济利益，因此公司以{交付合同约定的全部产品}作为收入确认时点"——"鉴于……无法……因此……"三段因果句。
- **市场份额口径调整透明化**："为使测算口径与公司收入统计口径匹配，在行业整体市场规模（分母）中剔除了{配套品类}的市场规模，经上述调整后，对应口径的{品类}20XX 年市场规模约为 X 亿元"。

### 四、族 C 结构类（问询回复骨架 · 通用）

- **多子问题独立成节**："问题 X、关于{主题}/ X.Y{子问题主题}：根据申报材料：{监管描述}。请发行人披露：{要求一}；是否{质疑二}。……回复：一、发行人披露；（一）{小点}；1、{论证节}……二、中介机构核查；（一）核查程序……（二）核查结论……"——每子问题独立成节、自成闭环、互不引用。
- **可比公司"三列对照表"**："公司与同行业可比公司{政策/模式}情况具体如下：{公司名称×时点×单据}……如上表所示，公司与可比公司{政策/模式}{不存在重大差异/差异系{业务模式}不同所致}"——境内/境外/安装/延保拆分子行，外销单列"报关单"单据口径。

### 五、族 D 论证类（结论句/论证链 · 通用）

- **营收下滑归因"综合结论"**："综上所述，报告期内，公司{收入/利润}下滑主要受{外因}影响，叠加{内因}……系{外部环境波动}与{公司阶段性战略投入}共同作用的短期结果，随着{外部需求复苏}与{内部经营效能持续释放}，经营业绩进一步下滑的风险较小，公司经营具备稳定性"。
- **募投"不新增产能"论证链**："本项目系{现有产品线}的{配套产能/智能化升级}建设项目……属于现有产品线的产业链配套延伸，而非新增独立终端产品线。产能消化路径清晰：一方面，{现有生产需求}客观存在且持续稳定；另一方面，充足的在手订单（截至 20XX 年 XX 月 XX 日为 A 万元）提供了直接的业绩基础与收益保障"。
- **第三方回款"成因分类+资金流闭环"**："报告期内{第三方回款}形成原因及合理性主要包括：①{成因一}（……属于{行业惯例}）②{成因二}……。上述{资金流}路径为：{客户委托→第三方付款→公司指定账户}。综上……不存在{虚构交易、资金体外循环、调节收入}等不合规情形"。
- **"无完全可比品类"如实披露**："{品类}目前境内外市场上尚无业务完全可比的上市公司/ {指标}难以实现完全对等的直接比较。为客观呈现行业普遍技术水平，结合{现行标准/招标要求/通用共识}，梳理形成相关技术指标的行业普遍应用水平"——找不到可比就明示，不硬凑对比。

## 引用规范

- 引用财务数据：「根据财务专家分析，发行人2023-2025年营业收入分别为...」
- 引用法律判断：「法律专家指出，发行人股权结构清晰，但存在...」
- 引用行业数据：「行业专家分析认为，发行人所在行业...」
- 引用知识库案例：「参考知识库中[XX项目]的处理方式...」

## 格式规范（通用底线，细节以 ibd-doc-review 为准）

- 正文：宋体，小四号，首行缩进2字符，1.5倍行距
- 数据：保留两位小数，金额单位统一（亿元/万元）
- 日期：YYYY年MM月DD日 或 YYYY-MM-DD
- **完整样式体系（000-009 招股书版 / 0011-009 反馈回复版）、序号九级链、表格 v2 规范** → 一律以 `ibd-doc-review` skill 为准，本文件不重复维护

## 语言风格

- 客观中立，避免主观臆断
- 数据说话，结论有据
- 投行专业术语，简洁明了
- 风险提示充分，不回避问题
