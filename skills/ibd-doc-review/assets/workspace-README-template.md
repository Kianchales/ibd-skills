## 三、每层干什么

| 文件夹 | 放什么 | 一句话判据 |
|---|---|---|
| `01_待复核材料/` | 客户发来的各版文件 | 别人给我的，我只读 |
| `02_参考资料/` | 规则准则、内部口径、同类范例、数据来源 | 判依据时要对照的 |
| `03_问题记录/` | 每轮查出的问题（按原文名分子目录） | 我查出来的，一轮一份 |
| `04_复核结果/` | 批注版、复核报告、修订稿 | 能发出去的 |
| `05_过程文件/` | 总览、台账、日志、临时脚本 | 只给自己看的 |

## 四、三条规矩

1. **`01` 只读**——不改、不移动客户原件；要改另存新版本。
2. **交付只从 `04` 取**——`05` 里的东西一律不对外。
3. **换基准必留痕**——每轮改认另一版时，在 `00_基准说明.md` 的「历史对照」追加一行。

## 五、命名

正式产物：`<原文名>_<YYYYMMDD>_v<N>_<形态>`
同一原文跨轮必升 `N`；同轮重跑直接覆盖。`<原文名>` 取基准文件简称，不随版本变。
