# 财务复核 16 维清单（check-dimensions）

> 用法：复核时按**四组 16 维**逐维度过「核查要点」问数据齐不齐/口径对不对/披露够不够；命中「关注信号」即起草问题条目。组序=损益与税务 → 资产与投资 → 报告主体与政策 → 报表勾稽与披露，按报表走查逻辑排列。
> 跨术语比对数据前先过 [term-caliber.md](term-caliber.md) 口径辨析表——先排除口径差（术语/含税/合并母公司/时点期间/单位），再定性勾稽问题。
> 问题类型只能取自本包 [issue-list-format.md](issue-list-format.md) §2 固定 10 类（下表「常见类型」列为映射提示，非新造类型）。
> 反模式红线（AP-F，源自投行财务核查实践）：勾稽不一致 / 收入口径错误 / 数据无来源时点 / 外部行情数据单位陷阱 / 可比公司口径错配 / 研发资本化边界不清。
> **准则引用策略**：各维「主要适用规则」只列**规则名称层**锚点（不锁条款号）——规则名称稳定可长期引用；具体条文按项目当期准则/监管版本核对，**禁止凭记忆写条款号**（错引条款比不引更糟）。
> **监管审核锚点（证监会发行类系列，2023-02 施行，首发业务财务审核问答汇编）**：IPO 财务复核除准则层外，须对照证监会《监管规则适用指引——发行类第 5 号》（财务审核标准 5-1~5-20，原首发业务若干问题解答整合）与《发行类第 9 号》（研发人员及研发投入）。各维映射：

| 维 | 发行类锚点 | 核心口径（要点） |
|---|---|---|
| 1 收入确认 | 5-12 经销模式 / 5-13 互联网业务 | 经销收入占比 >30% 须专项核查；返利计提充分性、经销商压货、放宽信用调节收入信号 |
| 2 成本与毛利 | 5-12 / 5-15 | 经销/委托加工毛利率异常联动资金流水核查扩大 |
| 3 研发费用 | **9 号全篇** / 5-4 研发资本化 | 研发投入口径=费用化+资本化之和；研发人员认定（非全时<50% 原则上不算、劳务派遣不算、受托研发不算）；研发产出品成本不得计入投入 |
| 4 股份支付 | **5-1**（核心） | **无等待期→一次计入+非经常性损益；有等待期→分摊+经常性损益**；公允价值考虑因素；回购权条款=隐含可行权条件判断 |
| 5 政府补助 | 5-5 科研项目补助 | 科研补助按收入准则 vs 补助准则分界；定额定量补助→经常性，课题类→非经常 |
| 6 税务合规 | 5-6 涉税 | 税收优惠经常性判定；补缴税款可追溯、罚款滞纳金计当期 |
| 7 应收款项 | 5-2 应收减值 | 组合划分依据；不得以关联/优质/政府客户为由免提；账龄起算时点；转商票连续计龄；有追索权保理按原账龄 |
| 8 存货 | 5-15 / 5-8 | 减值与周转联动；内控不规范（账外账/体外循环）信号 |
| 9 非流动资产 | 5-3 客户资源 | 客户资源确认为无形资产的条件（合同性权利+可控）；营销费用不得资本化 |
| 10 减值商誉 | 5-3 | 合并确认无形资产的识别与估值风险 |
| 11 投资金融资产 | 4-3 对赌 / 5-18 投资收益占比 | 对赌条款负债/权益判断；合并外投资收益占比高须披露被投企业非经影响 |
| 12 合并范围 | 4-5 出资瑕疵 / 4-4 | 出资瑕疵、资管产品持股的合并与披露边界 |
| 13 政策变更/差错 | **5-9** | 申报前=审计调整+差异鉴证；申报后变更/差错更正四核查点（时间影响/性质合规/是否基础薄弱/披露充分）；滥用政策估计红线 |
| 14 现金流量 | 5-10 现金交易 / 5-11 第三方回款 / 5-15 资金流水 | 现金交易 8 核查点；第三方回款 8 核查点；流水核查范围扩大情形 |
| 15 财务指标 | 5-16 未盈利 / 5-19 分红转增 | 未盈利原因量化披露；在审期分红论证、转增须更新审计报告 |
| 16 关联交易 | 5-8 财务内控 / 5-15 | 资金占用 10 类不规范情形清单；关联方流水核查 |

> 第 3 号（保荐执业）、第 6/7 号（再融资）、第 8 号（注册规程）、第 10 号（招股书披露格式）属程序/披露格式层，非财务判断锚点；第 4 号股东类中 4-3/4-4/4-5 与财务边界相关（已映射）。发行类第 2 号（2021）已废止，由《证监会系统离职人员入股拟上市企业监管规定（试行）》替代。

> **列报格式证伪信号（机械筛查，2025-09 回填自报表格式/年报通知精读）**：① 新准则企业（CAS 14/16/21/22 已施行）报表仍现「可供出售金融资产」「预收账款大额挂账」「利润表无信用减值损失行次」→ 准则版本错用信号；② 保险公司 2023 起利润表首行应为「保险服务收入」而非「已赚保费/保费收入」（财会〔2022〕37 号），否则未按新格式列报；③ 一般企业（财会〔2019〕6 号）/金融企业（财会〔2018〕36 号）/合并报表（财会〔2019〕16 号）按主体类型对照格式行次，报表科目与格式体系不符即报。

## 第 1 组　损益循环与税务

### 1. 收入确认

| 项 | 内容 |
|---|---|
| 核查要点 | 收入确认时点法 vs 时段法选择与依据；验收条款（签收/验收/报关时点）；收入跨期（截止性测试）；总额法 vs 净额法（代理人/主要责任人判断，考虑运输/安装等是否构成单项履约义务）；销售返利/退换货/质保的会计处理；新科目组：合同履约成本（履约中成本归集）、合同取得成本（**增量成本且预计可收回**方可确认，摊销计入损益）与存货的边界 |
| 关注信号 | 收入增速远超同行但无解释；期末突击确认（第四季度占比畸高）；客户签收与验收间隔异常；同一业务两种确认模式混用 |
| 主要适用规则 | CAS 14《收入》；首发审核关于收入确认政策与截止性测试的问询要点 |
| 常见类型 | 合规·一致性（模式选错）、数据·勾稽（收入与合同/回款对不上）、披露·充分性（确认政策披露不足） |

### 2. 成本与毛利

| 项 | 内容 |
|---|---|
| 核查要点 | 料工费构成与波动；毛利率年度趋势与同行业对比；毛利率口径（含税/不含税、是否扣运费）；成本归集完整性（有无期间费用混入成本）；**人工成本归集与薪酬水平合理性（生产/管理/研发人员划分、人均薪酬与同行及当地水平对比，防压低薪酬调节利润）**；存货结转与收入匹配；**重资产行业成本制度锚点（《企业产品成本核算制度》及分行业制度）**：煤炭/石油石化矿区权益、勘探开发与弃置义务成本须**产量法折耗**计入成本；钢铁回收物料/能源按**市价冲减**成本；电网共同费用年末按实际固定资产原值/输电量**重算调整**；制度第四十八条禁止以计划/标准/定额成本代替实际成本且期末不调差异 |
| 关注信号 | 毛利率远高于同行且无技术/模式解释；毛利率逐年背离行业趋势；同类业务不同产品毛利率悬殊无说明；成本结构剧变；人均薪酬显著低于同行/与业务扩张方向背离（劳务外包与自有员工结构异动） |
| 主要适用规则 | CAS 1《存货》（成本归集）；CAS 14（收入成本配比）；CAS 9《职工薪酬》（人工成本）；招股书披露准则「财务会计信息」章节（毛利率披露口径） |
| 常见类型 | 数据·口径（含税口径不清）、表述·衔接（与同行对比口径不一致）、披露·充分性（毛利率波动原因披露不足） |

### 3. 研发费用

| 项 | 内容 |
|---|---|
| 核查要点 | 资本化 vs 费用化边界（研究/开发阶段分界）；资本化时点与条件（技术可行性/未来经济利益）；研发加计扣除与高新资质匹配；研发人员认定（工时/兼职）；研发投入与募投项目关系 |
| 关注信号 | 资本化比例显著高于同行；资本化时点前后矛盾；研发费用率骤变；研发人员数量与薪酬不符（人均薪酬异常） |
| 主要适用规则 | CAS 6《无形资产》（开发阶段资本化条件）；高新技术企业认定管理办法；研发费用加计扣除政策（企业所得税法及实施条例） |
| 常见类型 | 合规·一致性（资本化条件不满足）、数据·勾稽（研发投入与加计扣除/高新数据对不上）、披露·充分性 |

### 4. 股份支付

| 项 | 内容 |
|---|---|
| 核查要点 | 公允价值确定方法（近期外部融资价/评估/其他）；摊销期间（等待期设定与依据）；对净利润的影响；是否适用股份支付（低价入股/员工持股平台）；行权条件与离职条款 |
| 关注信号 | 授予价格显著低于公允价值无解释；等待期认定与激励方案矛盾；股份支付费用处理前后不一致（是否一次性确认） |
| 主要适用规则 | CAS 11《股份支付》 |
| 常见类型 | 数据·口径（公允价值口径不清）、合规·一致性（与 CAS 11 不符）、数据·勾稽（费用对报表影响算错） |

### 5. 政府补助

| 项 | 内容 |
|---|---|
| 核查要点 | 与资产相关 vs 与收益相关分类（补助用于购建长期资产与否）；总额法 vs 净额法选择与一致性（冲减资产/递延收益 vs 冲减成本）；与日常活动相关→计入其他收益或冲减成本费用、非日常→营业外收支；**科目路径**（指南）：与资产相关补助总额法先计递延收益、在资产寿命内分期转入其他收益/营业外收入，净额法在资产达预定可使用状态时冲减资产账面价值；确认时点（满足所附条件且能收到）；政策性贴息两种拨付方式处理；补助退回处理；**与收入准则边界**（政府作为商品/服务对价组成部分时应适用 CAS 14 而非补助） |
| 关注信号 | 补助分类口径前后不一致；递延收益长期挂账不按资产寿命摊销；大额补助集中于报告期末确认（利润调节）；实质为销售对价（价格补贴）误按补助净额处理；补助退回未披露处理 |
| 主要适用规则 | CAS 16《政府补助》；CAS 14（政府作为客户对价的边界）；监管规则适用指引——会计类（其他收益/营业外收支列报口径） |
| 常见类型 | 数据·口径（总额/净额、日常/非日常分类不清）、合规·一致性（边界适用错误）、披露·充分性（依赖度与退回风险） |

### 6. 税务合规

| 项 | 内容 |
|---|---|
| 核查要点 | 税收优惠依赖度（高新/软件/出口退税）；历史补税风险；税负率与同行/自身利润匹配；递延所得税资产确认（可抵扣暂时性差异/未来应纳税所得额判断）；所得税费用与利润总额勾稽 |
| 关注信号 | 税负率远低于同行；税收优惠占利润比重大且临近到期；递延所得税资产确认依据不足（未来盈利预期激进）；大额补税未充分披露 |
| 主要适用规则 | 企业所得税法及实施条例；CAS 18《所得税》（递延所得税） |
| 常见类型 | 披露·充分性（优惠依赖风险）、数据·口径（递延所得税口径）、合规·一致性 |

## 第 2 组　资产与投资

### 7. 应收款项与减值

| 项 | 内容 |
|---|---|
| 核查要点 | 账龄结构；坏账计提政策（组合/单项、比例与同行）；**范围覆盖应收票据（尤其商业承兑）、应收款项融资、合同资产、其他应收款等应收类金融资产，逐类核减值**；**ECL 计量路径**（指南）：应收款项、合同资产、租赁应收款简化处理——直接按存续期预期信用损失计量（无需评估信用风险是否显著增加），其余金融工具按三阶段模型；客户集中度；回款周期与信用政策；应收账款与收入匹配度 |
| 关注信号 | 收入增长但回款恶化（应收增速远超收入）；账龄迁徙异常；计提比例显著低于同行；期末放宽信用政策冲收入；商票占比上升；合同资产/其他应收款漏提减值 |
| 主要适用规则 | CAS 22《金融工具确认和计量》（预期信用损失模型） |
| 常见类型 | 数据·勾稽（应收与收入/现金流不匹配）、合规·一致性（计提政策与准则/同行不符）、披露·时效（坏账风险披露滞后） |

### 8. 存货

| 项 | 内容 |
|---|---|
| 核查要点 | 跌价准备计提（可变现净值测试）；库龄结构与长库龄占比；周转率趋势；发出商品/在途物资确认；盘点制度与差异处理 |
| 关注信号 | 存货增速远超收入（积压信号）；库龄 1 年以上占比上升但未计提；跌价计提比例异动（前低后高「洗大澡」）；周转率骤降无解释 |
| 主要适用规则 | CAS 1《存货》（跌价准备/可变现净值测试）；首发审核关于存货监盘与跌价的问询要点 |
| 常见类型 | 数据·完整性（库龄/跌价测试披露缺失）、数据·勾稽（存货与采购/成本不衔接）、披露·充分性 |

### 9. 非流动资产与折旧摊销

| 项 | 内容 |
|---|---|
| 核查要点 | 固定资产折旧政策（年限/净残值/方法）与同行业可比；在建工程转固时点与借款费用资本化（达到预定可使用状态前后划分）；已达到预定可使用状态暂估入账、竣工决算后调整不调已提折旧；固定资产后续支出资本化 vs 费用化（更新改造 vs 修理）；无形资产摊销（含使用寿命确定 vs 不确定判断）；**新租赁准则承租人单一模型**（指南）：所有租赁确认使用权资产+租赁负债（短期租赁、低价值资产租赁简化豁免除外），使用权资产参照固定资产折旧、租赁负债按固定周期性利率确认利息费用；各类非流动资产减值迹象联动下一维 |
| 关注信号 | 折旧年限/残值率显著异于同行（拉长年限摊薄利润或相反）；在建工程长期挂账不转固；已投产项目仍将借款费用资本化；大修/替换支出处理前后不一致；产能利用率与资产规模背离；**费用口径混用**（旧口径「租金费用」与新准则「使用权资产折旧+租赁负债利息」并存的勾稽断裂；租赁负债是否纳入有息负债口径未标注） |
| 主要适用规则 | CAS 4《固定资产》；CAS 6《无形资产》；CAS 17《借款费用》；CAS 21《租赁》（使用权资产）；CAS 8《资产减值》（减值联动） |
| 常见类型 | 数据·口径（折旧/摊销口径不清）、合规·一致性（转固时点/资本化处理错误）、披露·充分性 |

### 10. 长期资产减值与商誉

| 项 | 内容 |
|---|---|
| 核查要点 | 减值迹象逐项判断（市价下跌/经营环境恶化/陈旧闲置等）；可收回金额 = max（公允价值−处置费用，预计未来现金流量现值）；资产组认定及其一致性（不得随意变更）；**商誉与使用寿命不确定无形资产无论有无迹象每年减值测试**；商誉分摊至资产组的方法（不超出报告分部）；含少数股东权益的商誉整体测试法；减值损失先抵减商誉再按比例抵减其他资产；**减值一经确认不得转回**（区别于应收 ECL 与存货跌价的可转回性）；减值后折旧摊销同步调整 |
| 关注信号 | 账面存在大额商誉但未见减值测试披露或测试假设激进（增长率/折现率异常乐观）；资产组划分逐年变更（规避减值）；减值损失集中确认（业绩变脸当期「洗大澡」）；商誉减值测试分摊范围大于报告分部 |
| 主要适用规则 | CAS 8《资产减值》（含资产组与商誉减值测试）；CAS 20《企业合并》（商誉初始确认） |
| 常见类型 | 合规·一致性（年度必测缺失/测试方法错误）、数据·勾稽（减值测算数对不上）、披露·充分性（关键假设未披露） |

### 11. 对外投资与金融资产

| 项 | 内容 |
|---|---|
| 核查要点 | 金融资产三分类判据（业务模式 + 合同现金流量特征）；理财产品/结构性存款分类（保本固定收益 vs 非保本浮动）；以公允价值计量且其变动计入其他综合收益的权益工具**指定不可撤销**；交易性金融资产公允价值计量与变动损益列报；长期股权投资成本法/权益法适用边界（控制/共同控制/重大影响判断）；权益法下未实现内部交易损益抵销（顺流/逆流）；处置投资损益计算（含原计入其他综合收益部分结转）；公允价值层级与估值技术披露 |
| 关注信号 | 保本型理财/定期存单分类口径与收益列报错位；持股比例临近 20% 上下无重大影响判断说明；通过处置参股/子公司投资在报告期末集中确认大额投资收益；公允价值估值方法/层级不披露或随意切换 |
| 主要适用规则 | CAS 2《长期股权投资》；CAS 22《金融工具确认和计量》（三分类）；CAS 39《公允价值计量》（公允价值层级） |
| 常见类型 | 合规·一致性（分类/核算方法选错）、数据·口径（公允价值与投资收益口径）、披露·充分性（层级与假设） |

## 第 3 组　报告主体与会计政策

### 12. 企业合并与合并范围

| 项 | 内容 |
|---|---|
| 核查要点 | 同一控制 vs 非同一控制判断（合并前后是否同受最终控制且非暂时性）；同控下账面价值法、差额调资本公积，并入当期期初即追溯（视同报告主体一直存在）；非同控下购买日确定、可辨认净资产公允价值分配、商誉初始确认；**合并范围完整性**（以控制为基础——表决权/合同安排/结构化主体/代理人身份判断）；内部交易抵销（未实现损益顺流逆流）；少数股东权益与少数股东损益变动；购买少数股权/不丧失控制权部分处置（权益性交易，差额调资本公积不入损益）；丧失控制权（剩余股权按公允价值重新计量、差额计当期投资收益） |
| 关注信号 | 报告期架构重组按同控认定并追溯调整但判断依据不足；合并范围变更未说明对比较期的影响；处置子公司/购买少数股权会计处理错误（该进资本公积的进了损益）；内部交易未抵销致合并数据虚高；同一控制下合并披露缺失（被合并方期初至合并日损益单列） |
| 主要适用规则 | CAS 20《企业合并》；CAS 33《合并财务报表》 |
| 常见类型 | 合规·一致性（同控/非同控认定或会计处理错误）、数据·勾稽（追溯调整/抵销数对不上）、披露·充分性 |

### 13. 会计政策/估计变更与差错更正

| 项 | 内容 |
|---|---|
| 核查要点 | 报告期内会计政策前后期一致性（不得随意变更）；政策变更合法性（法律/准则要求或更可靠相关）与追溯调整法应用（累积影响数调整列报前期最早期初留存收益并同步比较数据）；会计估计变更未来适用法（折旧年限/坏账比例等调整）；难以区分政策/估计变更时按估计变更处理；重要前期差错追溯重述；变更与更正对三年一期可比性、财务指标的影响披露 |
| 关注信号 | 申报期内变更收入确认/政府补助列报/折旧政策等且理由不充分（调节利润嫌疑）；差错更正涉及申报期且未按追溯重述处理；追溯调整未同步调整比较数据或调整金额有误；政策变更/差错更正未在附注披露原因与影响金额 |
| 主要适用规则 | CAS 28《会计政策、会计估计变更和差错更正》；首发审核关于申报期会计政策一致性与差错更正的问询要点 |
| 常见类型 | 合规·一致性（变更/更正处理方式错误）、数据·勾稽（追溯影响数计算错误）、披露·充分性（原因与影响未披露） |

## 第 4 组　报表勾稽与披露

### 14. 现金流量

| 项 | 内容 |
|---|---|
| 核查要点 | 经营活动现金流与净利润匹配（收现比/净现比）；大额投资/筹资活动现金流出；资金流水与业务实质（回款方与客户一致性）；分红与资金需求矛盾 |
| 关注信号 | 净利为正但经营现金流持续为负或背离；收现比异常低/高；现金流出方向与募投/业务不符；「存贷双高」 |
| 主要适用规则 | CAS 31《现金流量表》 |
| 常见类型 | 数据·勾稽（现金流与利润表/资产负债表不匹配）、披露·充分性（现金流向披露不足） |

### 15. 财务指标

| 项 | 内容 |
|---|---|
| 核查要点 | 关键比率趋势与口径（ROE 加权/摊薄、毛利率、资产负债率、流动/速动比率）；**每股收益（基本/稀释）计算口径与列报**；指标计算口径跨章节一致；与同行可比性说明 |
| 关注信号 | 同一指标在「财务会计信息」与「业务与技术」「发行人概况」披露数值不一；ROE/负债率口径标注缺失；可比公司选取无标准 |
| 主要适用规则 | 招股书披露准则「财务会计信息」章节（指标计算口径要求）；CAS 30《财务报表列报》；CAS 34《每股收益》 |
| 常见类型 | 数据·勾稽（跨章节不一致）、数据·口径（计算口径不清）、表述·衔接 |

### 16. 关联交易与关联方

| 项 | 内容 |
|---|---|
| 核查要点 | 关联交易定价公允性（与第三方比价）；交易必要性（是否依赖关联方）；关联方资金占用/担保；关联方非关联化（转让真实性）；关联交易占比与逐年变化 |
| 关注信号 | 关联交易定价无对比依据；关联方非关联化后仍大额交易；资金往来余额异常（占用迹象）；关联采购/销售占比逐年升高 |
| 主要适用规则 | CAS 36《关联方披露》；招股书披露准则「关联交易」章节；交易所关联交易监管规则 |
| 常见类型 | 披露·充分性（定价公允性披露不足）、数据·勾稽（往来余额对不上）、合规·一致性 |
