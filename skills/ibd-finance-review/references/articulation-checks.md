# 勾稽机械核对式（articulation-checks）

> 定位：check-dimensions / term-caliber / case-signals / interpretation-notes 四层知识管「查什么、怎么判」，execution-discipline 管「每个数都必须核、怎么核才算数」，本册管**机械可算项具体怎么算**——算式、方向符号约定、容差判据、差异表结构与表式变体识别。
> 触发：执行 SKILL.md 步骤②（全量核对登记）中「机械可算项先跑脚本全量扫」一节；复核范围含**报表、附注明细表、科目余额数据、问询回复中的科目数**时逐类执行。
> 来源：算式、方向约定与映射表**本地化改写自市场包「财务报表审核助手」（`financial-statement-auditor` v1.6.0，`license: MIT-0`）**；已按文档复核口径重写。**只取算式与判据，不取引擎与表格解析工具**——本包零硬依赖定位不变。

## 一、方向符号约定（算式前置）

取数前先给每个余额定方向，否则「负数」会被误读为异常。

- **借增类**（余额正常在借方）：资产、成本、损益 → **净额 = 借方 − 贷方**
- **贷增类**（余额正常在贷方）：负债、所有者权益 → **净额 = 贷方 − 借方**
- 异常方向的余额（资产现贷方余额、负债现借方余额）**按负数参与计算**——这正是往来重分类的成因，**不得先取绝对值再算**
- 与细则 1 的顺序：先定分母三态（账面余额/账面价值/均值）→ 再按本节约定的方向取净额 → 最后比口径（term-caliber）→ 才可定性勾稽问题

## 二、四类机械勾稽算式

复核范围含报表/附注明细表/科目余额数据时逐类执行；每类先判「数据齐不齐」（不齐按细则 4 标 B/C 级），齐则算。

| # | 算式 | 等式 | 命中信号 |
|---|---|---|---|
| ① | **总账平衡** | Σ(一级科目期初借方余额) = Σ(期初贷方余额)；**期末同理** | 借贷合计不等 ⇒ 底稿/明细表本身不平 |
| ② | **往来逐户净额重分类列报** | 见 §三 | 报表往来项目 ≈ 一级科目**整体轧差**数 |
| ③ | **损益倒轧** | 利润表各损益科目（本月/累计）= 科目余额表对应损益类**一级科目**本期/累计发生额 | 差额非零且已排除口径差 |
| ④ | **未分配利润勾稽** | (期末 − 期初) = 利润表本年累计净利润 ± 以前年度损益调整 − 提取盈余公积 − 分配股利 | 差额无法由上述可解释项覆盖 |

### ① 总账平衡

- 一级科目 = 无父科目者（按科目编码前缀推导：点分式去末段；纯数字逐级去末两位）
- 期初、期末各判一次；不等时列「借贷净额不为零的一级科目」清单（编码／名称／借／贷／净额）
- 依据：基本准则「有借必有贷、借贷必相等」——一级科目合计相等是总账平衡的必然结果

### ③ 损益倒轧的两式

利润表有两种表式，**项目式必须先拆解再勾稽**，否则整表误报：

| 利润表汇总行（wrapper） | = 科目余额表组成部分（损益类一级科目） |
|---|---|
| 营业收入 | 主营业务收入 + 其他业务收入 |
| 营业成本 | 主营业务成本 + 其他业务成本 |

- **科目式**：每行即一个损益类一级科目 → 按名称直接勾稽
- **项目式**：先按上表拆解，再与各组成部分的发生额**之和**勾稽
- 自然方向侧：收入/利得类（含「收入」「收益」「利得」）取**贷方发生额**；成本/费用/损失类（含「成本」「费用」「支出」「损失」「税金」「减值」）取**借方发生额**；比较取绝对值
- 利润表**内部计算项**（营业利润／利润总额／净利润／综合收益总额）非一级科目直接发生额，**不参与**勾稽，单列「需人工核对」
- 组成部分在科目余额表缺对应一级科目（汇总项无解构）→ 提示需人工核对，**不判为不平**

### ④ 差额可解释性排查

```
差额 = (期末未分配利润 − 期初未分配利润) − 利润表本年累计净利润
未分配利润变动 ≈ 净利润
                + 以前年度损益调整（贷增）
                − 提取盈余公积
                − 分配股利
                + 盈余公积补亏
                ± 其他综合收益结转等
```

- 检索路径：`以前年度损益调整`（通常 6901）取「累计贷方 − 累计借方」；`应付股利 / 利润分配`（4104 等）取「累计借方」作分配影响
- 差额可由上述项解释 → 通过；不可解释 → **提示性结论**，标注「可能另有盈余公积计提/其他调整，须结合所有者权益变动表判断」——**不武断判为错误**（与细则 4 的 B 级「待披露过程不臆断」同源）

## 三、往来款项逐户净额重分类（算式 ② 展开）

**重分类单元 = 「一级科目 × 辅助核算对象」**；无辅助核算列时回退「一级科目 × 末级明细科目」。

设某往来一级科目下、某户的期末借方合计 `D`、贷方合计 `C`，按正常方向取净额 `N`：

- 资产类（应收账款／预付账款／其他应收款）：`N = D − C`
- 负债类（预收账款／应付账款／其他应付款）：`N = C − D`
- `N > 0` → 留在原资产负债表项目；`N < 0` → 该户净额**整体重分类**至对方项目（取 `|N|`）
- **不同辅助对象之间互不抵销**

| 资产负债表项目 | 归集来源（逐户净额法） |
|---|---|
| 应收账款 | 应收账款各户 `N>0` 之和 ＋ 预收账款各户 `\|N<0\|` 之和 |
| 预收款项 | 应收账款各户 `\|N<0\|` 之和 ＋ 预收账款各户 `N>0` 之和 |
| 预付账款 | 预付账款各户 `N>0` 之和 ＋ 应付账款各户 `\|N<0\|` 之和 |
| 应付账款 | 预付账款各户 `\|N<0\|` 之和 ＋ 应付账款各户 `N>0` 之和 |
| 其他应收款 | 其他应收款各户 `N>0` 之和 ＋ 其他应付款各户 `\|N<0\|` 之和 |
| 其他应付款 | 其他应收款各户 `\|N<0\|` 之和 ＋ 其他应付款各户 `N>0` 之和 |

- **同户借贷并存先轧差**：客户X 借500、贷200 → 该户 `N=+300` → 列应收账款 300
- **为什么不能整体轧差**（报此问题的判据）：应收账款下 客户甲借1,000、客户乙贷200 → 整体轧差得 800，把客户乙（实为预收）的 200 抵销掉，**应收账款与预收款项同时低估**；逐户口径下 客户甲 1,000 列应收、客户乙 200 列预收
- **结论口径三件套**（清单 description 必须齐）：**重分类后应填列金额 − 报表填列金额 − 差异**；差异 ≤ 容差记「已正确重分类」，仍按 §四 进批注

## 四、容差判据（0.01 · 只用于定性，不用于过滤）

> 口径来源：**用户裁定（2026-09-24）——「勾稽过程中 0.01 就属于容差」**。

- **默认容差 = 0.01**——**按该表的列示精度取最小位**：列示到小数点后 2 位 → `0.01`（元则 1 分、万元则 100 元）；列示到元 → `1`；列示到万元整数 → `1` 万元。比较前**先把两表换算到同一列示单位与同一小数位**（[term-caliber.md](term-caliber.md) 单位陷阱条）——**「0.01」指列示单位的最后一位，不是绝对 0.01 元**
- **百分点列同口径**：占比／比例／百分比列**同样放行 0.01**（即 **0.01 个百分点**）——数值与金额列同为 `0.01`，量纲为百分点（2026-09-24 用户裁定补明）
- **求和型比对另加 n 倍允差**：「**n 项求和 vs 合计**」的比对（表内合计行、占比列合计）除 `0.01` 外，还须吸收各行按列示位四舍五入的**累积漂移**——每项上限半个列示位，n 项上限 ＝ `n × 0.01/2` ⇒ **容差 ＝ `max(0.01, n × 0.005)`**。**有界**：漂移超上限仍按实质差异报（例：30 行 ×3.33% ＝ 99.90% 对合计 100.00%，差 0.10 ≤ 允差 0.15 ⇒ 放行；30 行 ×3.32% 差 0.40 ＞ 0.15 ⇒ 报）。**单值比对（同一数在两处出现）不加 n 倍**，仍为 `0.01`。（2026-09-24 用户裁定「可以加 n 倍允差」）
- **不设相对容差**：勾稽等式比的是**同一个数**（同一审计报告口径下的同一科目），相对容差（如 0.5%）在大额科目上会吞掉实质差异（营业收入 5 亿 ⇒ 放行 250 万），与 0.01 口径不相容。确需放宽的场景（跨准则衔接、口径重构等）须**在执行说明里显式声明并留痕**，不得默认启用
- **用法边界（关键，勿越界）**：容差**只**用于判断「该差异属**列示精度舍入**还是**实质差异**」，据以定**类型与严重度**；
  **不得用于决定是否批注**——execution-discipline 铁律 2 已明确「占比舍入级不一致」这类小问题**也要批注、一个不落**。
  - 差异 ≤ 列示位 0.01 → **仍进批注**：严重度取低，类型取「数据·勾稽」或「表述·衔接」，description 写明「属列示精度舍入，口径为…」
  - 差异 > 0.01 → 按量级与方向定中/高危
- 顺序不可倒：**先统一单位与列示精度 → 再排除口径差（term-caliber）→ 再用容差吸收舍入 → 最后定性**。用容差掩盖口径差是最常见的误用

## 五、差异表与算式留痕模板

机械层每条不匹配按同一结构取数，同时落逐数台账（细则 2「算式留痕」的算式形态）：

| 口径 | 项目 | 本方（报表/正文） | 对方（附注/余额表/审计报告） | 差额 | 方向 |
|---|---|---|---|---|---|
| direct / wrapper · 本月 / 累计 | 营业收入 | 6,000.00 | 6,000.00 | 0.00 | 收入(贷) |

- 台账「算式/说明」列直接写该行算式（分子／分母／来源页码齐）；**无算式的「✅ 一致」视为未验证**（细则 2）
- 问题清单 description 引用时必须带**两处原文依据 ＋ 差额**，不得只写结论；锚点按细则 8 取唯一
- 对照表类数据先认栏位方向（更正前/更正影响/更正后）与正负号语义（细则 3），本模板的「方向」列即为此设

## 六、表式变体识别清单（防「因表式非标而漏核」）

非标准表头是漏核的首要成因。取数前先按下列变体归一，**归一后再匹配**，匹配不上才记「跳过」：

| 变体 | 归一动作 |
|---|---|
| 科目异名（应收账款/应收款项、预付款项/预付账款…） | 关键词模糊匹配，不要求全等 |
| 「帐」与「账」混用 | 先做「帐→账」归一 |
| 双栏式资产负债表（左资产 ＋ 右负债权益） | 先判栏位归属再取数，勿按单栏解析 |
| 利润表行首/行尾装饰（「加：」「减：」「一、」「二、」「其中：」、"(亏损以"－"号填列)"） | 勾稽前剥离前后缀，剥离后再与科目名匹配 |
| 科目余额表辅助核算列命名差异（辅助核算／辅助项／辅助档案／扩展辅助项／核算项目／核算维度／核算对象／核算因子／往来单位／往来核算／客商／客户／供应商／部门／员工／项目…） | 按关键词族识别；识别不到再回退「一级科目 × 末级明细」 |
| 无编码/名称但带辅助核算数据的明细行 | 视为其上一父行的明细（继承父行编码/名称）；**只进重分类，不进平衡与倒轧**，防重复计算 |
| 金额单位（元／千元／万元／亿元） | 先统一单位再比对，保留单位溯源列（term-caliber「单位陷阱」条） |
| 对方（企业/审计）另附的重分类对照表 | 先认表头栏位与正负号语义再引用（细则 3） |

## 七、不作为清单

- **不评价业务合理性**：本册只判勾稽与平衡性；业务实质、会计处理恰当性、披露充分性归 check-dimensions 与 case-signals
- **不内置引擎**：不引表格解析脚本、不读 PDF、不依赖第三方包——算式与判据由人/模型执行，或交可选增强的表格勾稽工具（见 [integration-and-fallbacks.md](integration-and-fallbacks.md) §2）
- **不产重分类稿**：本册不出「重分类后报表」文件；如企业/底稿需要，属底稿层交付，另行处理
- **不替代审计**：本册命中的不平不直接等同于审计调整事项，须回企业账套与原始凭证定位——结论用语按执行纪律「未替审计师/保代下结论」
