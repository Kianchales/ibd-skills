# 对接声明与替代管理（Integration & fallbacks）

> 本 skill **单层公开、完全自足**：整个目录可原样分发，不内置任何本机私有配置，不要求外部组件存在。
> 与外部组件的协作一律通过**文档内声明**完成——本节声明每条对接协议与可选的增强来源；
> 对应组件缺失时按「替代方案」降级，本 skill 功能不受损。

## 1. 复核结论交付（对接协议）

问题清单的字段与编号设计本身就是对接协议，任何消费方按字段读取即可，无需改造：

| 协议点 | 约定（详见 issue-list-format.md） | 对接方动作 |
|---|---|---|
| 字段 | code / type / severity / anchor / title / description / suggestion | 按字段消费；锚点最小可定位句段 |
| 复核人代号 | J=财务、L=法律、I=行业、Z=综合（前缀进 code） | 多专业复核时按代号分流汇总 |
| 交付形态 | 批注版原文 + 精简总览（编号一一对应）；**只加批注，不改原文** | 支持 Word 审阅批注或 PDF 高亮的批注工具均可落地 |

- **有批注/门禁体系时**：问题清单直接对接——docx → Word 审阅批注，PDF → 高亮弹注；数值自洽类机械检查脚本先跑，人工聚焦剩余存疑项；走修订流程时先确认形态（修订留痕 / 直接改好 / 双版）。
- **没有时**：问题清单 markdown 本身即是交付物，零工具依赖。

## 2. 依据检索（证据链路径，缺源即降级）

每条问题须能回答「依据是什么」，按序检索；前一顺位不可用即降级到下一顺位：

| 顺位 | 来源类型 | 缺失时替代 |
|---|---|---|
| 1 | 《企业会计准则》具体准则条款、证监会/交易所审核问答（**公开法规**） | 无——公开法规是底线依据，任何环境可获取 |
| 2 | 同类案例：已公开项目的问询与回复 | 无内部案例库 → 用交易所公开披露的问询函件与回复 |
| 3 | 可比对标：毛利率/指标异常时拉同行可比数据 | 无行情数据服务 → 用可比公司年报/招股书**公开财务数据**人工摘录；解析外部数据必须**保留单位/币种溯源列并做量级校验**（单位错配是高频翻车点） |

## 3. 演进与同步（无外部依赖）

- 新关注信号 → 回填 references/check-dimensions.md 对应维度
- 新问题类型 → 先在 references/issue-list-format.md 词表登记，**禁止复核时自造标签**
- 若工作区既有词表/格式规范与本包同源（字段、类型词表一致），保持同步维护即可；本包词表为**公开自足版**，独立可用

## 边界：本 skill 不含什么

- 无本机路径、无内部知识库标识、无内部项目名、无数据服务凭据——目录内无任何分发前需剔除的内容
- 使用方的本机接线（知识库入口、数据服务凭据、内部规范位置）由使用方自行配置，不进 skill 包
- 内部案例库 / 内部行情服务在公开版中一律表述为「可选增强来源」，非必需依赖

## 为什么采用此模型

- **单层维护**：只有一份公开内容，发布即整包，无「打包排除/私有目录」心智负担
- **声明驱动**：对接方看到协议即可互操作；替代路径保证任何环境下都能独立交付复核结论
- **天然过发布门禁**：全目录可扫、零私有引用，隐私/外部引用/依赖来源门禁一键通过
