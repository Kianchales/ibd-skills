# ibd-finance-review

IBD 财务章节深度复核 —— A 股 IPO 招股书及申报文件的财务专业内容复核 skill。

## 定位

投行文档审查三层模型的**专业判断层**：核查财务口径、勾稽关系、会计处理、披露充分性。格式/排版归格式层 skill，通用内容质量（数字溯源/绝对化/反模式）归内容质量层 skill。

## 核心内容

- **16 维复核清单**（`references/check-dimensions.md`）：四组走查——损益循环与税务（收入/成本毛利/研发/股份支付/政府补助/税务）·资产与投资（应收款项/存货/非流动资产/减值与商誉/对外投资与金融资产）·报告主体与会计政策（企业合并与合并范围/政策变更与差错更正）·报表勾稽与披露（现金流/财务指标/关联交易）——每维含核查要点、关注信号（命中才报问题）、主要适用规则（名称层锚点）、常见问题类型映射
- **术语与数据口径辨析**（`references/term-caliber.md`）：高频混用术语对的细微差距（研发投入≠研发费用、归母≠净利润、合并≠母公司口径…）+ 翻车点 + 「对不上」判定流程——口径错配类问题的专用依据
- **监管案例信号库**（`references/case-signals.md`）：按 16 维组织的实务争议场景与监管口径（源自《上市公司执行企业会计准则案例解析（2024）》《企业会计准则实施典型案例集（2022）》与历年年报会计监管报告，名称层引用）——维度复核时对表本案
- **问题清单字段规范**（`references/issue-list-format.md`）：code（复核人代号 J=财务）/ 固定 10 类类型词表 / 严重度三档 / 锚点规则——复核结论与批注/修订落地工具之间的标准接口
- **对接声明与替代管理**（`references/integration-and-fallbacks.md`）：复核结论交付协议、依据检索降级路径、单层公开边界
- **复核执行纪律**（`references/execution-discipline.md`）：全量核对铁律——范围内每个财务数字必核必重算、零遗漏零跳过；分母三态（余额/账面价值/均值）还原、算式留痕、对照表方向确认、验证 A/B/C 分级、跨章引用一致性（引用数据回源比对/业务数量价勾稽/外部数查标注五要素）、逐数台账模板
- **五步复核流程**：锁定范围与数据基准 → 全量核对登记（零遗漏）→ 维度复核 → 依据检索 → 汇总问题清单

## 使用

触发词：「财务复核」「财务章节审查」「招股书财务复核」「毛利率核查」「收入确认审查」「财务勾稽」。

问题清单产出后可对接任意批注工具原位落地（Word 审阅批注 / PDF 高亮），交付形态 = 批注版原文 + 精简总览；只加批注，不改原文。无批注工具时问题清单 markdown 本身即交付物。
