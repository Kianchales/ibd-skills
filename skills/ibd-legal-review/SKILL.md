# ibd-legal-review（IBD 法律惯例对照复核）

## 定位

投行文档的**法律惯例对照**：拿手上的稿子，去案例库找**同类情形**，比「**别人怎么写、本稿像不像样**」，出一张**对照标注**。

**只对照、不定性**——「这条到底构不构成明股实债」「控制权是否稳定」这类**性质判断归签字人**，本技能只摆事实（本案写法 vs 库内 N 案惯例），供签字人裁决。

**在链路里的位置**：本技能是**格式复核包（`ibd-doc-review`）声明单 D 域（法律）的执行承载**——复核链走到 **L3 档**时被触发，与财务域之于财务复核包同构。产出交回复核包汇总，**本技能不自出报告**。

## 何时使用

**链语境**：文档复核链 · L3 档 · 检查项声明单 · D 域（法律）查项。
**本技能动作词**：法律惯例对照｜同类情形怎么写｜特殊情形处理｜单列与穿透｜除外式表述｜敏感议题的**惯例对照**（只标注、不定性）。

两条触发路径，**产出同一形态**：

1. **复核链声明单 L3 档触发**——复核包进门声明了 D 域查项，本技能逐族执行；
2. **用户直接点名**——「查一下这段的法律惯例」「同类情形市场上怎么写」。

### 与法律分析线的区分（防抢命中）

| | **法律分析线**（专家团 agent） | **本技能** |
|---|---|---|
| **动作** | **分析 → 给结论** | **对照 → 摆事实** |
| 输入 | 一个**问题** | 一份**已成形的文档** |
| 产出 | 法律分析意见 | 对照标注（本案 vs 库内 N 案） |
| 所在层 | 专家团（team-lead 派单） | 复核链（声明单 L3 触发） |

**判据一句话**：要「**这条合不合规、构不构成 X**」→ 走分析线；要「**同类情形别人怎么写、本稿像不像样**」→ 走本技能。

> 两者**共享依据来源**（同一套法规源与案例库）**不算冲突**——区别在**动作**，不在资料。

## 复核流程

> **第 0 步**是全流程的前提，不可跳过；缺了它，后面引的条款可能不是「当时有效」的版本。

### 第 0 步 · 先定事实发生时点

**法规未来适用、不溯及既往**——判断任何事项，**先定「事实发生时点」**（行为／事项**发生日**，**不是**文件出具日、**不是**申报日），再取**该时点有效的法规版本**。**不得用后法评判前事**；跨期事项**分段**各取其时点版本。

### 进门（复核链 L3 档触发）

1. 判定本次是否含法律专业复核（L3）；
2. **确定适用时点**（第 0 步）；
3. 声明本轮 D 域查项（清单 → [check-items.md](references/check-items.md)）。

### 四步法 · 惯例对照

方法本体落在**复核包**（跨域共用件），本技能**只引用不复制**：→ `ibd-doc-review` 的「惯例对照四步法」分册。

| 步 | 动作 |
|---|---|
| **① 取例** | 按情形类型去案例库调同类案处理（走**方法论检索能力**，**编号即引用**；**未安装可忽略**——退化为按族卷定向读）；族号 → 族名 → 卷路径见 [families.md](references/families.md) |
| **② 对照** | 本案写法 **vs** 库内同类案惯例——比**处理方式**（单列／合并／穿透／除外式），**不比措辞好坏** |
| **③ 标注** | 产「本案写法 vs 库内 N 案惯例」对照条目，引条目编号；**只摆事实、不出建议** |
| **④ 敏感议题兼容** | 命中敏感议题清单 ⇒ **只产对照标注**，禁建议／禁核查程序／禁承诺函 |

### 出件

**标准问题条目**（类型标签用复核包既有词表，**不新造**）＋ **对照依据**（案例库条目编号 ＋ 法规条款号 ＋ **适用版本**）⇒ **交复核包汇总**。

> **清单结构与字段以 `ibd-doc-review/references/interface.md` §3 为准**（机器版 `problems.schema.json`）；**落地交 `ibd-doc-annotate`**（批注/修订交付执行器）。

## 判定标准

> 三档怎么分、人机线在哪、四条红线是什么 → 全在 [criteria.md](references/criteria.md)。本节只给一句话索引。

| 档 | 情形 | 判据依据 |
|---|---|---|
| **A 明文** | 法规／规则有明文要求 | 以条款为准（**须为适用时点有效版本**） |
| **B 惯例** | 无明文或灰色地带 | 以市场惯例为准（多案共通） |
| **C 敏感** | 命中敏感议题清单 | **不定性，只标注** |

**人机分层**：本域属 **L3**——**AI 只提质疑、只摆对照**，**定性与结论归签字人**。其中**形态层事实**（是否单列、是否给了该声明、是否有对照表）可机械校验，但仍属 L3 档的产出。

**四条红线**（摘要，全文 → [criteria.md](references/criteria.md) §3）：① 不以措辞好坏论；② 不引未核实条款；③ 敏感议题禁三类（建议／核查程序／承诺函）；④ **版本匹配**（引条款须为**事项发生时**的有效版本）。

## 边界与协作（不做四条）

| # | 不做 | 归谁 |
|---|---|---|
| 1 | **不给法律定性结论**（明股实债／控制权／对赌等性质判定） | 签字人；AI 只有质疑权 |
| 2 | **不查会计处理恰当性** | 财务复核域 |
| 3 | **不查板块特殊格式**（√适用/□不适用 等勾选式）、**不做格式层检查** | 格式复核域 |
| 4 | **不自出报告、不产修订稿** | 复核链单一汇总口 ＝ 格式复核包 |

> 查项**按 19 族**组织、**全挂 L3**；族内条目为**取例来源**，不上升为查项。缺口族（占位项）**未填前不勾不提**。
> **上游**：格式复核包的声明单（L3 档）；**下游**：问题条目 ＋ 对照依据交回格式复核包汇总。**方法不在本包**——四步法归格式复核包（跨域共用件），本包只引用。

## 依赖与工具

> **三问**（须自备资产 / 挂载方式 / 缺失降级）——本技能按**公布包标准**设计，**不假定接收者拥有任何本机私有资产**。

| 维度 | 说明 |
|---|---|
| **须自备资产** | ① **法规依据源**（🟡推荐 · A 档明文核对的依据；**可自举**）② **方法论库**（🟡推荐 · B 档惯例对照的承载，用 `{METHODS_ROOT}` 占位符；**建库／蒸馏／维护** → `ibd-methods-ops`，**按问题查库** → `ibd-methods-query`）③ 包间依赖 **`ibd-doc-review`**（**不随包携带**，断链自助）④ **随包自带** [fetch_law.py](scripts/fetch_law.py)（**无需自备**） |
| **挂载方式** | 方法论库用 `{METHODS_ROOT}` 占位符（同写作／检索包的后端约定）；**法规源不设占位符**——无源时按 [sources.md](references/sources.md) 规程从**官方公开源**实时取 |
| **缺失降级** | ① **无法规源** ⇒ 官方公开源实时取自举；**取不到 ⇒ 标注「未核实」**，不得据以定性；② **无方法论库** ⇒ **B 档退档为 A 档**，如实交付「无例可取」，**B 档不在承诺内**；③ **缺 `ibd-doc-review`** ⇒ 断链，按包内自助指引补装 |

- **运行时**：Python 3 标准库；[fetch_law.py](scripts/fetch_law.py) 的 **PDF 路径**需**可选依赖 PyMuPDF**，缺失时**明确提示而非静默失败**。
- **承诺边界**（A 承诺／B 须自备／无源须标注）→ [sources.md](references/sources.md)。

## 踩坑要点

- **不默认取现行版**——法规**未来适用**，判断历史事项须取**当时有效版本**；同一部法多版本并存时，版本线索＝取件时的「版本」字段，缺则显式标注「未核实」。
- **不引未核实条款**——引条款须可回溯到权威文本；取不到原文的**显式标注**，不静默跳过。
- **动作轴防抢命中**——本技能管「对照摆事实」，法律分析结论走分析线；两段描述都可能被「法律」类措辞命中，靠**动作**切开。
- **包内零私有字样**——按公布包约束，包内**不写**任何私有路径／私有库名／工作区名，一律改述为「使用者的法规库」「使用者自备的案例库」。

## 维护

- **改查项** → 只改 [check-items.md](references/check-items.md)（D 域明细的唯一事实源），并同步格式复核包的 D 域登记；**A/B/C/F/S 编号与档位零改动**。
- **改族名或族号** → 以案例库卷标题为准，同步 [families.md](references/families.md)（**不得自行改名**）。
- **族与条数回填** → 见 [families.md](references/families.md)「**巡检回环**」：蒸馏入库后巡检「库卷 ↔ 19 族」——族内新条目更新快照、**族外新卷登记「新族候选」**（**≥3 次复现才立族**）；敏感议题类族按 C 档建条目。
- **改判据或红线** → 只改 [criteria.md](references/criteria.md)；**时点匹配**与**四条红线**是判定前提，改动须回改 SKILL.md「复核流程·第 0 步」与本包版本号。
- **改取用规程或承诺边界** → 只改 [sources.md](references/sources.md)；**取件脚本**的输出头部须与其版本纪律保持一致。
- **规则变更须同步** → ① 册本体 ② [SKILL.md](SKILL.md) 相应节 ③ `CHANGELOG.md` ＋ 版本号 ④ 下游引用（格式复核包的 D 域登记、四步法册的域接法）。
