## 取例方式

1. **定位族** —— 按情形类型在上表找到族号与族名（族名以案例库卷标题为准，**不得自行改名**）。
2. **取例** —— 按**方法论检索能力**（`ibd-methods-query` §检索流程）定位到条目，**编号即引用**；**未安装该能力可忽略** —— 按本册「**定位族 → 读该族卷 → 按条目编号取用**」这条**自足路径**即可。族卷内**每一条目**为一段「规则要点 → 实证 → 适用场景」，取其中**处理方式**作对照物。
3. **引用** —— 引用时给**条目编号**（形如 `L-<族号2位><序号4位>`）＋ 该族卷名；**不复制正文**。
4. **无例可取** —— 案例库缺失或为空时，**如实交付「无例可取」**（B 档退档为 A 档），**不假称已对照**（承诺边界 → [sources.md](sources.md)）。

### 检索预算（防无界查询）

| 项 | 预算 | 理由 |
|---|---|---|
| **查询面** | 只查**本次已声明 D 域查项**对应的族；**不遍历全库** | 复核是**定向**的，不是普查 |
| **每族命中即止** | 命中 **≥3 条**相关条目即够（惯例通常在 3 案内收敛）；不足 3 条则读满该族卷 | 与「立族判据 ≥3 复现」同源 |
| **全文路兜底** | **仅在族卷定向读无匹配时启用**；同义词／别名变体**宜为个位数**；命中即止 | 承上游检索能力的双路纪律 |
| **需跨族时** | **另起一轮**，不在同轮内扩大面 | 防「顺手全查」 |

> **为何要定预算**：大库下全文路兜底可能**无界** ⇒ 查得越多、结果越不聚焦。**预算优先于覆盖率**。

> **与查项的关系**：本册是**取例来源**索引；**查什么**由 [check-items.md](check-items.md) 定义（一族一项）。两者一取一查，不互相替代。

## 巡检回环（族与库的持续对齐）

**19 族不是静态清单** —— 它的更新源是**方法论库的蒸馏产物**（库法律域**按族分卷**，卷即族）：

```
蒸馏（ibd-methods-ops）→ 库法律域新增条目／新增族卷 → 本包巡检比对 → 更新族内快照 或 登记新族候选
```

**巡检动作**（每次蒸馏入库后，或复核开工前顺手做一次）：

| 情形 | 动作 | 落点 |
|---|---|---|
| 族内**新增条目** | 更新本表「条目数」**快照**（**仅供规模参考，不作用据**） | 本册族索引表 |
| 库出现**19 族之外**的新卷 | 登记「**新族候选**」，**不直接加族**（先攒复现） | 本册 §新族候选 |
| 族名／族号变化 | **以库卷标题为准**同步本册 ＋ 查项册 ＋ 格式复核包的 D 域登记 | [check-items.md](check-items.md) ＋ 跨包 D 域 |
| 新增**敏感议题**类族 | 按 C 档建条目（**不判定、只标注**） | [criteria.md](criteria.md) §三档 |

> **软依赖**：巡检读库需 `ibd-methods-query`（检索通道）；库的**生产与维护**归 `ibd-methods-ops`；**两者皆缺时**按本册「取例方式」的**自足路径**独立运行，功能不受损。

> **库对账（巡检动作 · 零脚本）**：**为什么不做脚本** —— 对账要同时读「**本册族索引**」与「**库卷目录**」，脚本落**消费包**会两份重复、落**库侧**则成跨包耦合（本包**不假定**库侧有该脚本）。故落成**动作**：① **列期望**（本册族索引表）② **列实况**（`{METHODS_ROOT}` 法律域目录下的卷文件）③ **逐条比对** —— **册有、库无** ⇒ 卷被改名或移除 ⇒ **以库为准**同步本册；**库有、册无** ⇒ **新卷** ⇒ 登记「新族候选」；**卷名不一致** ⇒ **以库卷标题为准** ④ **回填**本表。
