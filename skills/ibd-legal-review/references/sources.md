# sources · 依据链与法规取用规程

> 依据从哪来、版本怎么定、库里没有怎么取 —— 全在这册。
> **本技能不内置法规原文、不写死任何本机路径**：依据源一律做成**开放后端 ＋ 降级链**（理由：本技能按公布包设计，接收者**不拥有**任何本机私有资产）。

## §1 三层依据源

```
惯例（方法论条目）──引──▶ 法规条款号 ──可回溯──▶ 法规条文全文（可核）
```

| 层 | 是什么 | 接收者有没有 | 处置 |
|---|---|---|---|
| **L1 法规** | 法条原文 | ❌ | **可自举**：按 §3 取用规程从官方公开源取；无源 ⇒ 标注「未核实」 |
| **L2 惯例** | 案例蒸馏条目（规则要点 ＋ 多案实证） | ❌ | **须自备**（取例走**方法论检索能力**；其**库接入与降级细则以该能力为准**，**本包不复制**）；**空库 ⇒ 惯例对照无例可取** |
| **L3 案例** | 案例原文（含案例实证与页码） | ❌ | 随 L2 —— 条目内的实证段落由其承载；案例汇编类资产由使用者自备 |

- **L2／L3 的关系**：L3 不单独成源——它**内嵌在 L2 条目**里（每条目＝「规则要点 → 实证（多案 ＋ 页码）→ 适用场景」）。故「无方法论库」＝ L2 与 L3 同时缺失。
- **取例通道**：见 [families.md](families.md) §取例方式；族卷内的**规范条款号**（条目直引的法规条款）是 A 档明文的常用依据。
- **可得性分级**：L1 **可自举**（不依赖本机资产）；L2／L3 **须自备**（不在承诺内）。

## §2 版本纪律（时点匹配 · 判定前提）

法规**未来适用、不溯及既往**（判定规则全文 → [criteria.md](criteria.md) §0）。取用与引用一律遵守：

1. **多版本并存** —— 同一部法在相关期间内修改过的，各版本**并存备查**，不得只留现行版。
2. **不得默认取现行版** —— 引用条文前先按**事实发生时点**选定版本；只有现行版时，须标注差异与所引版本。
3. **取不到原文或版本不明 ⇒ 显式标注「未核实」** —— 不得据以论证、不得据以定性；**不静默跳过**。
4. **版本线索的落点** —— 取件产出的**头部「版本」行**（施行日期／修订版次）是唯一版本线索；取件时**务必写清所引版本**，未填则须显式提示。

> **落地**：取件脚本 [fetch_law.py](../scripts/fetch_law.py) 的输出头部固定含「版本」行；未传版本备注时**显式打印「未填」提示**，不静默。

## §3 法规取用规程（L1）

> **只写方法与官方源，不写任何本机缓存路径**——取回的原文存哪里，由使用者指定（默认当前目录下的 `legal-refs/`）。

### 3.1 开放后端三档

| 档 | 后端 | 动作 |
|---|---|---|
| **A · 本地法规库** | 使用者自有的法规库（任意目录，**路径由使用者给定**） | 按名检索 → 定位条文 → **按事实时点选版本**后引用 |
| **B · 官方公开源实时取** | 全国人大网、中国政府网／国务院公报、部委官网、交易所官网、省市政务公开页 等 | 用随包脚本或直接抓取 → 清洗 → **质检** → 落使用者指定目录 |
| **C · 无可用源** | — | **显式标注「未核实」**（§2 第 3 条），不得据以定性 |

### 3.2 缺失降级三态

1. **有库** → **直读**，并按**事实时点**选版本；
2. **无库** → **官方公开源实时取**（规程随包为**必须**；取件脚本为**建议可选件**，属加速器）；
3. **取不到** → **显式标注「未核实」**，**不静默跳过**。

### 3.3 取源优先级

1. **优先官方网页源**（部委官网／政府网／人大网）——文本干净、可核；
2. 网页无全文（只有扫描件／附件）⇒ **取其官方 PDF 附件**抽取；
3. 扫描件 PDF 留作**存档原件**（可逐字比对），**不作文本源**。

### 3.4 已探明的取源障碍（照抄结论，省去重复探路）

| 源 | 状态与处置 |
|---|---|
| **商业法规数据库**（账号／积分制） | 常不可用（额度耗尽／鉴权失败）⇒ **不作主路径** |
| **国家法律法规数据库** | 只提供**扫描件 PDF**（无文字层），部分行政法规附件为空、文档格式路径不可得 ⇒ **只作存档／比对源，不作文本源**；其下载域 HTTPS 证书可能过期 |
| **部分监管机构站点（SPA 动态渲染）** | 直取只得外壳 ⇒ **跳过**，改走政府网／部委**静态页** |
| **搜索引擎** | 结果常为跳转链接（可解）；站内搜索 API 可能不返结果 ⇒ **定位官方页宜逐部检索**，不依赖站内搜索 |

> ⚠️ **自动检索不可靠** —— 故本包**不做自动检索**：URL 由使用者或 AI 用公开检索定位后传入，脚本只负责「取件 → 清洗 → 质检 → 落盘」这段可机械化部分。

### 3.5 取件质检判据

- **主判据**：**行首条号 1→N 连续**（只数行首，天然排除条文内互引他法条号造成的假缺号）；
- **退路**：行首条号过少（排版异常）⇒ 退回「去重条号数」；**名录／表格类**（本无条号）⇒ 以中文字数兜底；
- **不过不落盘**：条号非 1→N 连续且无条号时中文 < 3000 字 ⇒ 报「疑未抓到正文」并**拒写**。

## §4 公布版承诺边界

| 档 | 承诺 |
|---|---|
| **A 明文核对** | ✅ **承诺** —— 依据获取**不依赖本机私有库**（可从官方公开源自举） |
| **B 惯例对照** | ⚠️ **须接收方自备案例库**；库缺失或为空 ⇒ **B 档不在承诺内**（**退档为 A 档**，如实交付「无例可取」，**不假称已对照**） |
| **C 敏感议题** | 本就只标注（不涉依据源） |

> ⚠️ **包内禁写**：私有资料库名／私有路径／工作区专名 —— 一律改述为「**使用者的法规库**」「**使用者自备的案例库**」；验收判据 ＝ 发布侧引用检查**零拦截**。
