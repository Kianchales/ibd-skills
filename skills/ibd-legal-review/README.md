<h4 align="center">19 族法律查项 · 时点匹配取版本 · 惯例对照四步法 · 只对照不定性</h4>

## 💡 这是什么

投行文档的**法律惯例对照**：拿手上的稿子，去案例库找**同类情形**，比「**别人怎么写、本稿像不像样**」，出一张**对照标注**。

**只对照、不定性** —— 「这条到底构不构成明股实债」「控制权是否稳定」这类**性质判断归签字人**；本技能只摆事实（本案写法 vs 库内 N 案惯例），供签字人裁决。

**在链路里的位置**：本文档复核链中 **D 域（法律）的执行承载**——复核走到深度档（L3）时被触发，产出交回复核链汇总。**本技能不自出报告**。

## ✨ 快速开始

```
「查一下这段的法律惯例」        → 取例对照，出「本案 vs 库内多案」标注
「这个特殊情形别人怎么处理」     → 按情形类型定位族 → 取例 → 对照
「看看这类条款的除外式表述」     → 单列与穿透／除外式处理方式的惯例对照
```

## 🧩 典型场景

| 场景 | 一句话 | 走哪本册 |
|---|---|---|
| 复核链声明了 D 域查项 | 逐族对照，出问题条目 ＋ 对照依据 | `references/check-items.md` |
| 想知道「这类情形别家怎么写」 | 定位族 → 取例 → 对照 | `references/families.md` |
| 要判断引用的是不是「当时有效」的版本 | 先定事实发生时点，再取版本 | `references/criteria.md` §0 |
| 手上没有法规原文 | 走官方公开源自取（可自举）；取不到就标「未核实」 | `references/sources.md` |

## 🧭 分工（与谁配合、与谁不重叠）

| | 法律分析线（专家团 agent） | **本技能** |
|---|---|---|
| **动作** | 分析 → 给结论 | **对照 → 摆事实** |
| 输入 | 一个**问题** | 一份**已成形的文档** |
| 产出 | 法律分析意见 | 对照标注（本案 vs 库内 N 案） |

**判据一句话**：要「这条合不合规、构不构成 X」→ 走分析线；要「同类情形别人怎么写、本稿像不像样」→ 走本技能。
两者**共享依据来源不算冲突**——区别在**动作**，不在资料。

## 📦 安装与依赖

> **三问**（需要使用者有什么 / 挂在哪 / 没有会怎样）。本技能**不假定接收者拥有任何本机私有资产**。

| 须自备资产 | 挂载方式 | 缺失降级 |
|---|---|---|
| ① **法规依据源**（🟡推荐；**可自举**）② **方法论库**（🟡推荐，用 `{METHODS_ROOT}` 占位符）③ 包间依赖 `ibd-doc-review`（**不随包携带**）④ **随包自带**取件脚本（无需自备） | 方法论库用 `{METHODS_ROOT}` 占位符；**法规源不设占位符**——无源时按 `references/sources.md` 规程从**官方公开源**实时取 | ① **无法规源** → 官方公开源实时取自举；**取不到 ⇒ 标注「未核实」**，不得据以定性；② **无方法论库** → **B 档退档为 A 档**，如实交付「无例可取」，**B 档不在承诺内**；③ 缺 `ibd-doc-review` → 断链，按包内自助指引补装 |

**承诺边界**（三段）：

- **A 明文核对** —— ✅ **承诺**：依据获取**不依赖本机私有库**（可从官方公开源自举）。
- **B 惯例对照** —— ⚠️ **须接收方自备案例库**；库缺失或为空 ⇒ **B 档不在承诺内**（**退档为 A 档**，如实交付「无例可取」，**不假称已对照**）。
- **C 敏感议题** —— 本就只标注（不涉依据源）；**无源须标注**「未核实」，不静默跳过。

**可选依赖**：`scripts/fetch_law.py` 的 **HTML 取件路径零依赖**；**PDF 取件路径需可选依赖 PyMuPDF**（`pip install pymupdf`），**缺失时明确提示而非静默失败**。
